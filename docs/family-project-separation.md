## 安全切换顺序

1. 准备独立家庭应用，建立私有仓库和 Production 基础设施。
2. 在健康源端发布带密钥校验的临时家庭迁移桥；家庭业务暂留至数据迁移和新服务核验完成。
3. 冻结家庭写操作，按固定白名单导出清单与附件；导入独立卷，核对 SHA-256、文件数和业务版本。迁移内容不写入仓库或日志。
4. 新端验证家庭登录、读取与上传/手动解析、制度、日期后，启用同域名路径转发；转发过滤 Cookie、Origin 和内部鉴权头。
5. 从健康构建与源码移除家庭业务，只保留路由转发；复核两项目可独立发布，再清除临时迁移凭据。

发布完成前，原端数据和服务继续保留。不能用旧服务的 SUCCESS 状态证明独立项目已发布。

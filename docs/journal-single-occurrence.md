# 日常安排与实际记录

日常作息继续通过成员范围的 `/api/routines/:memberId` 保存通常时间段。默认仅内置夜间睡眠；早餐、午睡、晚奶等通过添加自定义作息保存。历史已保存的固定项目继续回填，避免再次保存时丢失。不自动写实际记录，不自动结束，也不投影计划卡片到时间轴。旧模板、实例链接与明确确认 API 保留兼容，不批量删除历史数据。

每条实际睡眠或喂养/用餐只占一个记录 ID。进行中位于开始时间；明确完成后更新相同记录 ID，并位于结束日期/时间。`shared/journal-occurrence.mjs` 集中定义时间归属，旧记录读取时按完整起止时间兼容，不修改审计时间、不创建起止副本。统计读取的记录数量仍为一次，完整起止时间及准确时长不受列表粗略显示影响。

饮食详情新增兼容可选字段 `name`（最多20字）、`note`（最多1000字）、`status`（ongoing/completed）。meal/feeding 支持真实 `startedAt`，进行中必须明确 status=ongoing 且没有 endedAt；完成要求 endedAt 晚于 startedAt。无 status 的历史完整起止区间视为已完成。名称或奶量不会推算时长。无区间饮食记录仍可照旧保存。

列表短时长显示分钟，至少一小时显示四舍五入后的约几小时。没有正时长则不显示。进行中只有轻微省略号，尊重减少动画设置。详情保留起止完整日期、准确时长、奶量、原文和补充字段；完成操作仅更新原记录，失败保留输入。

验证覆盖：跨整点/午夜/多日单条归属、正在运行的预计醒来不自动完成、旧时间兼容、无时长奶量/仅名称、同ID更新/重试、按成员的计划保存与回填、不产生计划记录、375/390/430px。

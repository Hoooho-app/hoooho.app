# 个人用量与全站资源监控 · 2026-11-04

## 任务契约（实现前）

产品主人要求：控制台立即接入监控；用户侧栏帮助/反馈/关于上移，账户信息移到底部，最下方显示资料容量和 AI 等成本用量；拟定付费扩容套餐。原件是否可在确认保存后不再保留，目前是讨论问题，不是删除授权。

普通案例：用户登录→打开侧栏→看到自己的资料占用估算和本月已计量 AI Tokens→展开用量详情，核对统计时间、范围及缺失项→继续原记录工作。管理员打开资源监控→查看真实文件系统余量、分类占用、增长和 AI 回执覆盖→容量告警在 Overview 出现→打开并定位源卡片后才确认已查看。切换未接入项目保持空状态。

### 数据与边界

- 全站盘：操作系统 statfs 可用空间；文件分类为逻辑文件大小，不能与分配块空间冒称完全相等。预警本次建议 70% / 85% / 95%，并保留至少 100 MiB 运维余量的提前提醒。共享盘告警只通知管理员，不要求某个用户付款。
- 个人资料：按服务端已验证账户归属，统计现有 JSON 业务集合、识别任务/资产和附件文件；同一二进制引用去重。属于资料占用估算，不作为收费账单；未支持的数据库/系统副本明确排除。账号参数不能由请求者任意指定。不返回原文、文件名、其他账户用量或服务器路径。
- AI：从上线后的真实供应商 HTTP 响应 usage 累计输入/输出 Tokens、调用与语音秒数；缺少回执保留未知次数，不补零、不从字符数估算、不把一次整理等同一次模型调用。失败响应同样计入监控，但不作为扣费凭证；实时语音 WebSocket 暂未覆盖。历史消耗无法补算。日汇总持久化，重启保留；监控失败不得阻塞健康记录。
- 本轮不增加模型调用/供应商、不修改原有调用限制；不改变账户/记录/家庭分享权限；不自动扩容、扣费、限流或删除原件。不向用户展示未启用的套餐额度进度。
- 付款渠道、合同及真实计费尚未接入；套餐作为管理员方案，不放置假支付入口。正式计费前还需确定计费单位、失败豁免、续费、退款、超额/降级与已有资料只读保留规则。

### 状态、恢复与副作用

- 加载/已读取/部分覆盖/读取失败分开；失败不显示 0 或“正常”。重试只读，不清缓存/记录。账号切换、退出、弹层关闭取消请求，迟到结果不串号。
- 磁盘采样与扫描缓存、并发合并，避免每个用户打开侧栏都扫描全盘；只有元数据汇总，绝不持久化健康内容副本。采样历史有界；采样持久化故障仍返回实时磁盘实测结果并标明历史不可用。
- 告警按严重度变化建立稳定版本；刷新不重复制造未读。告警消退后已生成的历史项保留有界，查看回执沿用 Overview 规则。
- 原件与查看入口保留。以后可设计“保留原件 / 核对后只存记录”，须明确不等于完整无损转换，原件下载和宽限期、失败/未确认不删、同一原件多处引用的保留规则。

## 套餐建议（未启用，不构成收费）

| 方案 | 月价建议 | 资料容量 | 每月输入 Tokens | 每月输出 Tokens | 每月语音 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 免费 | ¥0 | 100 MB | 30,000 | 10,000 | 5 分钟 |
| 标准 | ¥19 | 1 GB | 1,000,000 | 250,000 | 60 分钟 |
| 家庭 | ¥39 | 5 GB | 3,000,000 | 750,000 | 180 分钟 |

输入与输出分别设置额度，避免高价输出吞掉利润。资料包可建议 ¥10/GB/月；先不销售“无限 AI”。语音转写后再次调用文字模型会同时计入文字额度。容量累计占用不按月清零；AI 按北京时间自然月重置，首月规则在正式计费前确定。共享资料只向实际存储所有者计量，避免重复收费。

成本校验示例基于阿里云公开价 https://help.aliyun.com/zh/model-studio/model-pricing：若实际使用的模型/地域确为输入 ¥2/百万、输出 ¥8/百万，标准文字额度最坏直接模型成本约 ¥4，家庭约 ¥12。不同模型/地域/上下文长度/缓存/优惠均会改变成本，不能将此推演宣称现网毛利。还需计入语音、存储、备份、流量、支付手续费、税费及失败调用；实际结算前以账单抽样核验。原件策略优化应在确认完整性后进行，不能先删除再验收。

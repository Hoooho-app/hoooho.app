# 总控台补全与费用自动采集（2026-11-01）

基线 origin/main bdb7d4487eb6c08e5e8d4fdbd9d78de4d15475d2，工作区干净；分支 codex/ops-automation-20261101。用户授权补全空白页面、自动读取费用页面和加强到期/额度/正常状态。

## 完整案例与数据边界
管理员在费用模块选择护护记录，看到每个来源的采集连接状态、最后核验时间和独立的费用状态。服务端每日08:00自动采集，关闭页面仍运行；已有授权会话的费用区域自动截图，同时从明确字段读取日期/余额/额度，保留私有快照和事实证据。域名到期使用官方RDAP公开事件自动读取，不推断扣款日期。缺少持续授权的平台明确待授权，绝不改成要求用户日常上传，不把截图成功当费用正常。余额或日期缺失保持未知，不凭OCR猜测。用户在Overview打开临期/不足提醒定位原来源，查看回执和问题解决分别管理；续期或补足后的新事实解除旧风险，跨阈值重新提醒。

本次常规默认：临近到期30/7/3天三级，额度剩余20%/5%，事实过期每日36小时/每周8天；只做站内提醒，不发送邮件/SMS或执行续费付款。允许管理员在工作台设置保存阈值，刷新保留。服务链接按项目显示受控的实际健康端点、延迟/检查时间与链接；配置存在不等于在线。版本管理只显示运行实例提供的真实提交与持久启动/部署回执，未接入项目/原生渠道明确未知，不伪造上线版本。顶栏、侧栏、原费用快照和反馈业务保持。

## 异步、恢复与权限
- 自动采集串行、有超时、来源请求合并；重启补采到期任务，失败保留旧截图及旧事实但标为过期/待核验。未接入来源不重复写失败历史。相同截图不复制文件，但更新本次核验时间；旧事实不能冒充新核验。
- 采集器只使用服务端专用授权浏览器地址和来源配置，不导出用户浏览器凭据、不自动操作验证码/MFA、不提交付款。固定供应商域名白名单、账单区域选择器和隐私遮罩；未配置区域不截整屏。配置中不含供应商密码；秘密不进入前端/日志。
- 来源、提醒、Overview、设置使用同一数据/项目归属；禁用来源不产生风险提醒，其他项目不复制健康数据。迟到请求不清理新版本动态。
- 项目切换、刷新、失败和重复点击均保持可恢复状态；设置失败保留输入，成功以服务器回执更新。所有新接口沿用唯一管理员校验。

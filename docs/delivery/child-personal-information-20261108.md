# 健康档案个人信息卡

基线为正式仓库 `main` 的 `fe4ce6b7`。改动覆盖健康档案首页及其现有身份资料编辑页。

- 打开健康档案，第一张卡显示当前孩子的头像、姓名、性别和年龄。身高、体重、血型一行三列，血压、脉搏下一行。基本资料目录保留身份与出生背景、生长记录。
- 例如，家长进入身份与出生背景，填写 `98/61 mmHg` 与 `92 次/分` 并保存。服务器按账户、孩子和身份档案版本保存。回到首页或刷新后，两项读取同一份已保存资料。姓名、性别、生日、血型及身高体重沿用各自原有来源。
- 血压两项一起填写或清空，脉搏可独立填写或清空。仅记录手动输入的数值，空值显示未记录。身高体重保留原测量日期与已确认数据优先规则。
- 读取失败可重试，保存失败保留输入。若档案版本冲突，核对最新档案后再提交。切换孩子或账户时重新读取，迟到的旧孩子数据不进入当前卡片。切换与未保存退出沿用现有入口。

验收覆盖同一行的三项、窄屏、空值、真实保存与回读、读取及保存失败、切换孩子隔离和既有目录入口。用隔离的虚构数据验证。

本地生产构建、824 项客户端检查、22 项定向检查通过。5 项浏览器用例通过，覆盖 320 至 1280 px 布局、八个目录入口、成长读取重试、血压不完整拦截、保存失败重试、刷新回读和孩子切换。实体 iPhone 验收另行核对。

# 健康档案个人信息卡

## 成长录入和标签简化

档案顶卡与成长数据快速录入区的身高、体重两项去掉日期。家长点身高进入身高曲线，输入新测量后直接保存，系统按当天记入成长记录。历史补录和曲线仍使用真实测量日期。身高曲线、体重曲线的选中态使用墨绿色和白字。验证以顶卡、快速录入、曲线切换、保存回读和历史记录为准。

构建、824 项客户端检查和 5 项档案浏览器回归通过。用隔离档案验证两个标签的实际颜色、当日保存、回读和顶卡不显示日期。

## 恢复直接操作

基线为 `main` 的 `2b2918fe`，分支为 `codex/restore-child-card-controls-20261108`。顶卡去掉标题、切换按钮、血压和脉搏。身份与出生背景页移除血压和脉搏入口，已经写入的资料随原档案保留。BMI 在身高和体重齐全时显示在头像区右侧。

家长点身高或体重进入原成长数据页，入口所选曲线优先于上次浏览的曲线。录入或核对历史测量后返回，顶卡读取原成长记录服务的当前数值。选择血型下拉项即提交当前孩子的 ABO 字段。只有保存回执更新顶卡，取消选择没有写入，失败保留原值和重试项。RhD 与资料来源沿用原档案。切换账户或孩子时迟到结果只可更新原账户和原孩子的资料。

验收覆盖窄屏可操作、两项曲线正确落点、返回和重新打开、血型保存与失败重试、成员隔离，以及新布局继续显示 BMI。

生产构建、824 项客户端检查、5 项档案浏览器回归和 3 项门诊情况单浏览器回归通过。测试使用隔离的虚构资料及本地实际保存接口。

## 初版记录

基线为正式仓库 `main` 的 `fe4ce6b7`。改动覆盖健康档案首页及其现有身份资料编辑页。

- 打开健康档案，第一张卡显示当前孩子的头像、姓名、性别和年龄。身高、体重、血型一行三列，血压、脉搏下一行。基本资料目录保留身份与出生背景、生长记录。
- 例如，家长进入身份与出生背景，填写 `98/61 mmHg` 与 `92 次/分` 并保存。服务器按账户、孩子和身份档案版本保存。回到首页或刷新后，两项读取同一份已保存资料。姓名、性别、生日、血型及身高体重沿用各自原有来源。
- 血压两项一起填写或清空，脉搏可独立填写或清空。仅记录手动输入的数值，空值显示未记录。身高体重保留原测量日期与已确认数据优先规则。
- 读取失败可重试，保存失败保留输入。若档案版本冲突，核对最新档案后再提交。切换孩子或账户时重新读取，迟到的旧孩子数据不进入当前卡片。切换与未保存退出沿用现有入口。

验收覆盖同一行的三项、窄屏、空值、真实保存与回读、读取及保存失败、切换孩子隔离和既有目录入口。用隔离的虚构数据验证。

本地生产构建、824 项客户端检查、22 项定向检查通过。5 项浏览器用例通过，覆盖 320 至 1280 px 布局、八个目录入口、成长读取重试、血压不完整拦截、保存失败重试、刷新回读和孩子切换。实体 iPhone 验收另行核对。

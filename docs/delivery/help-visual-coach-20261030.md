## 完整任务与范围

家长从任一页面侧栏进入帮助，先看到手动记事和睡眠两项图文主教程；按需展开其他现有操作。读图后点跟着做，在真实页面用半透明灰黑蒙版及透明洞聚焦实际控件，用户自己填写、核对和保存，取得真实回执后指向准确记录。没有孩子先按现有流程添加。退出帮助返回原页面并保留未发内容。

帮助页与操作图解覆盖当前公开目录；为手动症状、睡眠、用药、喂养/饮食、排便接入真实记录引导，为查找、档案、成长、语音、就诊整理/复制导出和回顾提供实际页面操作定位。隐藏功能、任务系统及未来规划继续不介绍。原账号、时间、AI、导出和保存协议不改。

## 业务与状态

- 图为明确标注的操作示意，不假冒真实孩子、后台记录或成功截图；示例不预填、不自动提交。
- 蒙版留真实洞，点击落在原控件，不能克隆输入、替用户点击保存或以“下一步”伪造业务完成。记录成功仍由现有eventId/recordId回执决定。
- 指导状态与正式记录/草稿分开，按账户、孩子、教程隔离。刷新恢复有效步骤；退出指导只撤蒙版并保留表单，可继续指导；原表单返回和草稿保护沿用。
- 填写步骤待真实输入，时间步骤由用户明确核对；保存失败留在原步并展示真实错误，支持原按钮重试。重复记录确认、附件、人体定位与重新登录弹层出现时暂停蒙版，不覆盖或阻止操作。
- 提示与目标共享当前弹层焦点域；Tab仅在当前操作与指导按钮中循环，Escape先退出指导，不同时退出表单。可滚动、键盘、visualViewport变化时重新测量；目标缺失时不画空洞、不锁整页，给退出/等待途径。
- 说明型页面的引导结束仅代表位置引导结束，不冒称资料已保存、复制或文件已下载；实际结果沿用原页面提示并由用户核对。
- 侧栏来源按账号/孩子约束并保留所有帮助内导航，支持刷新后返回；只允许安全站内路径，清除一次性导航意图，直接访问帮助回首页。

## 验收契约

- 母乳、配方奶、瓶喂母乳、混合喂养、辅食、正餐、零食统一“出现症状（可选）”。新开及编辑默认折叠，展开仅自由文本，不保留选项按钮。
- 收起不删除文字，不填不推断正常。原数组字段兼容旧选择和草稿；输入限1000字，保存、详情及重开编辑不丢失。沿用既有权限、孩子/账户隔离、失败重试及同ID修改。
- 母乳、辅食复用现有名称与实际时间同行控件；名称按类型隔离，时刻仍禁止未来值。
- 混合喂养、正餐、零食等共用外层固定与内部单轴滚动，边界拖拽不带动背景；仍允许滚动、缩放及短屏输入。
- 补剂使用与其他类型相同的区块间距；未要求补剂新增症状栏。
- 所有手动记录表单的“（可选）”统一现有caption字号/400字重；HohoInput的同文案后缀同步，保留完整可访问名称。

普通案例：补记昨天辅食 → 填食物/名称/过去时间 → 可选展开症状、输入观察原话 → 收起 → 保存实际回执 → 时间线查看 → 同一条记录编辑/清空症状 → 保存后仍同ID。奶类依方法保留时长/奶量、各自草稿；食物分类继续共享当前饮食草稿。返回/刷新保留原机制；保存失败留输入，连续点击不重复提交。计时与后台切换原机制保持。

范围只包含该表单与保存/详情、共享可选文字、滚动锁的显式局部开关。其余业务、AI、家庭项目、导航、原生发布冻结。仅现有症状数组的单项长度上限扩大到1000字，不迁移既有数据。

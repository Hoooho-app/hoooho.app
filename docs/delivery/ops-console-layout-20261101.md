## 完整使用与范围
管理员登录 → 进入 Overview 待查看收件箱 → 按项目/关键词筛选真实新情况 → 选中只预览，不减少数字 → 打开源反馈或费用快照并定位 → 内容实际显示后持久化已查看回执 → 回 Overview 数字减少，刷新/重开保留；新补充或新快照重新进入待查看。历史未查看跨天保留；查看不是处理完成，失败不能算已看，无一键清空。费用原有快照/大图/更新/上传/管理功能保留；只补板块内项目选择与来源归属。旧来源默认仍属于原护护记录，不复制到其他项目。其他项目未接入时为空，不伪造跨项目反馈或健康数据。

侧栏固定为 Overview、费用监控、反馈中心、服务链接、版本管理；底部工作台设置。顶栏只有管理员信息与退出；项目在各板块内切换。服务链接、版本管理、设置仅空白页，不虚构未建设能力；告警不另设菜单，目前只从已有费用失败/重新登录状态产生真实提示。备案域名继续关闭，使用原 Railway Production 入口；不重发 iOS 包。

## 状态与直接依赖
- 原唯一管理员鉴权、费用私有存储、反馈可见性/回复/处理规则、产品页面及两产品的数据隔离不变。项目标签仅控制已登记来源归属，不建立新的服务/数据拷贝。
- Overview 只合并现有费用变化和反馈线程的最新用户动态；初次使用保留尚无本收件箱查看回执的历史动态，不把处理状态冒充已查看。回执只保存事件 ID 与查看时间，保留在原私有持久卷。
- 预览不读取会写入查看时间的反馈详情接口。打开源内容成功渲染后才确认，失败不清除数字；事件 ID 含快照/补充版本，迟到的确认不能清除较新的动态。
- 反馈精确链接、费用来源 ID 锚点可刷新和重开；坏链接明确显示错误，不确认查看。项目/路由切换取消读取，不能显示上个项目的响应。费用归属改动由管理员显式保存。
- 带鱼屏使用剩余全宽，Overview 列表+摘要并排；笔记本切单列或折叠处理区，不保留反馈页旧 1180px 最小宽度。沿用 V2 token 与 Material 图标。

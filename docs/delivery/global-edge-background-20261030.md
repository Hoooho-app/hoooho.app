## 任务与验收契约

家长在手机打开症状记录，切换健康日历、孩子档案、整理、账户与其他可见页面，滚动、打开/取消弹层、收起键盘和刷新后，背景持续铺到屏幕上下边缘。顶部状态栏沿用当前页面的实际底色，底部导航背景延续到系统横条区域；按钮和文字保留安全距离。

本次只修改网页与原生外壳的颜色衔接/底部覆盖范围。记录、草稿、账户/孩子归属、保存与导出协议、原生附件和分享保持原样。不重设纸张/主题颜色，也不移除避让刘海和系统横条的安全距离。

| 规则 | 责任位置 | 验证 |
| --- | --- | --- |
| 网页顶部颜色、浏览器工具栏、原生顶部外围同步 | PageAppearanceEffects + NativeBridge + WebViewController | 普通页、开屏深色、主题切换、弹层开关、刷新/返回 |
| 底部背景到屏幕边缘且只有一份安全距离 | WebViewController bottomAnchor 到 view.bottomAnchor；现有 CSS env(safe-area-inset-bottom) 保留 | 原生 UI 几何/边缘像素检查；网页主要导航/手动表单/弹层 |
| 失败/旧包/取消仍能继续当前页面 | 可选原生 appearance 能力；不涉及持久化操作 | 无新桥接的普通浏览器；原有附件桥接测试 |
| 不接受子帧或外部页面设置原生颜色 | 现有 native origin/main-frame 限制 + RGB 校验 | 桥接测试、Swift 色值验证 |

刷新恢复仍以原有会话与草稿为准，颜色变化不触发记录写入。异步/重复颜色通知幂等；页面卸载清理观察器与事件。普通页面使用原有背景，开屏和主题颜色跟随实际可见页面，弹层半透明遮罩做颜色合成。

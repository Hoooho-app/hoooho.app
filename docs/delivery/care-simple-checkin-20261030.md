# 呵护之旅简化为签到与成长

基线 `0bb76f314392aca7fd8e044ccf569f90295669b5`，干净分支 `codex/care-simple-checkin-20261030`。复用完整用户流程交付技能及 V2 组件。

## 用户任务与范围

家长在空白首页从今日呵护进入；开始说话出现实际消息、恢复历史或其他状态使欢迎区卸载时，孩子信息旁出现同款3D小芽入口。其显示与现有 `showHomeWelcome` 同源，未发送文字不切换入口；显式新对话恢复卡片并隐藏顶栏入口。顶栏小芽只负责导航，不自动签到。进入后保留每日领取、树芽累计、原等级、成就；移除兑换、主题购买、钱包/消费说明、每日阅读/档案核对任务及所有装饰标语。只改本链路，不扩展帮助中心和隐藏工具。

普通案例：空白首页点领取，服务端每天按账户时区记一次 +1 → 卡片显示已领取 → 家长记录情况，卡片卸载、顶栏小芽出现 → 点小芽进入呵护之旅，今日已领取且同一累计/等级 → 查看成长或成就并返回 → 首页恢复原会话。取消录音、未发送文字维持原卡；失败保留消息时显示顶栏入口。

## 数据与恢复

- 保留账户级签到、树芽账本/累计、等级阈值 0/20/60/150/300、原有已获得成就及权益；不删除健康记录、会话、旧交易或余额。首页“已守护”继续按当前孩子建档日计算，与签到次数分开。
- 每次签到仅在真实回执后更新；忙碌禁用重复提交，失败重试，同日并发/跨入口/刷新不重复奖励，跨日可再次领取，断签不重置。账户切换沿用隔离；切换孩子不重复发账户奖励。
- 停止记录触发的每日任务 +2；任务核对/材料接口返回停用，无新材料或任务奖励。原有第一份记录/第一次整理成就保留；原“初程完成”从双任务要求改为累计30次签到（本次常规选择），已点亮不撤销、不重复奖励。七次呵护继续累计签到，不要求连续。
- 兑换旧路由回到呵护之旅，公开兑换API返回停用且不扣费；目录不显示可买内容。原权益读取与已保存结果可用，不清除既有主题或权益。服务内部的历史权益/快照实现保留，避免破坏直接依赖。
- 进入旅程不触发AI或写健康数据；返回首页沿用既有会话自动保留。加载和失败只显示必要状态及重试，不冒称已领取；等级页与成就页从同一服务端数据读取。

## 验收

- 服务回归：同日并发、跨日/断签、历史数据保留、停用任务后无 +2、30次成就、旧兑换/任务API不产生奖励或扣费。
- 移动浏览器：320/390/430宽，欢迎卡与顶栏入口互斥、未发送/第一消息/失败/历史/新建、顶栏可点且不重叠，旅程返回保留消息；领取/重试/刷新/成就/等级、旧链接退回、无任务/兑换/标语。
- 构建、相关客户端与服务检查 → main → Production SUCCESS → 线上只读检查。真实生产奖励不用于验收，实体iPhone与用户视觉验收单独记录。

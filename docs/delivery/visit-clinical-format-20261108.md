# 就诊情况单按门诊病历编排

基线 `e9cf428f`，隔离分支 `codex/visit-clinical-format-20261108`。范围为就诊情况单、情况单复制与 HTML 导出、健康档案顶部 BMI。沿用现有成员归属、主诉选择、附件、源记录、资料范围、历史快照和版本保存协议。末句暂按保留「本次想问」处理。

家长在整理入口打开当前孩子的单据。系统用最近有效症状作为默认主诉，按发生时间读取当前主诉相关的一周记录。家长看到已记录的喷嚏、流涕和明确写下的伴随症状。没有记载的项目仍可见为补充提示，初始无选择。家长点「无」补录恶心，点「是」确认明确观察到的体格项目。保存回执返回后刷新、复制及导出均反映同一版本。

- 默认主诉、明确选过的主诉与事件入口分别沿用自动、固定与指定事件。发生时间未知的原话可供当前主诉参考，不作为有日期的经过。时间模板及已有事实分开，不能从病名、空白、正常体温或其他事项推导阴性结论。体格肯定项只有明确的医疗记录或家长主动选择才成立。
- 保存以孩子、报告版本和主诉范围为边界。新增或清空只改当前单据里的对应项。请求失败可在原行重试，冲突重读后由用户重试。切换主诉读取该主诉的已保存补充，不串用上一主诉。按同一请求标识重试，不新增原始症状或体检记录。
- BMI 使用当前已确认的身高、体重，一项缺失时留空，只显示数值。情况单保留文字姓名、性别、年龄、出生日期、身高、体重。导出排除未确认的模板提示，原始依据保留在附录。

核验依据为合成鼻部主诉和不同事件／日期的记录、真实本地持久化、浏览器手机视口、纯文本和 HTML 的同版本结果，以及构建和线上实际版本。

本地验证通过。生产构建、客户端 824 项、情况单服务端 97 项、375／430 px 与桌面浏览器情况单 12 项、档案浏览器 5 项。验证覆盖无原话入口、明确否定与未知留空、真实本地回读、保存失败重试、主诉切换隔离、BMI 和 HTML 导出。实体 iPhone 与正式入口需独立验证。

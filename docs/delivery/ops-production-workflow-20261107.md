# 护护记录 · 生产工作流

基线：正式仓库 main `2ef4658b84111b898aa9034de39b43f2c22b2bab`。范围：总控台侧栏「工作流」、管理员只读 API、区域/发布流程图与节点详情；不修改生产流量、存储、账户、模型配置或任何用户流程。

## 普通案例和验收

管理员打开「工作流」，先看国内正式链路，再点 Agent 查看实时字幕、松手转写、对话追问、识图、整理输出分别绑定的供应商和模型。切到海外时看到共享入口及单独部署的证据缺口，而不是复制国内模型状态。切到发布后可分别核对 Web、TestFlight、商店、小程序；测试包不等同生产后端。点相邻节点可继续追踪，浏览器返回、刷新保留视图和节点；错误时可重读，旧读数必须明确标成上次快照。

## 状态依据

- “进程已响应”只来自当前已鉴权服务，不代表跨地区可达、数据卷可写或供应商正常。云平台地域和部署版本只读已登记环境元数据，不猜测。杭州切换和旧服务保留是带日期的迁移回执，不是实时探测。未验证海外独立路由，不能把旧 Railway 当作海外主站或声称自动容灾。
- AI 状态读取本进程真实工厂／实例，不发模型请求；显示未配置、配置异常、已配置待实测及本地能力。不展示密钥、供应商 URL、文件路径、个人资料、输入或日志。Agent 是编排，并非单一模型。单次配置读取不代表地区和保留政策验证通过。
- 国内及海外不再由浏览器位置或语言猜测。查看视图及详情只写 URL 导航状态，不切流、不改数据、不触发发布。地域的架构回执落后于事实时，更新回执和实际运行配置，不将仓库代码提交冒充线上版本。
- 验证需覆盖匿名/非管理员不可读取、正常查看、节点深链接、区域切换、重试、窄屏、保护性字段及路由回归；验证不花费 AI 额度，不写生产健康数据。

发布时，部署系统可显式登记本实例的 `OPS_WORKFLOW_SITE`（仅 `aliyun-hangzhou`、`railway`）和 `OPS_WORKFLOW_RELEASE_SHA`（正在发布的完整 Git SHA）。迁移复制过来的旧云平台变量不代表本实例地域或新版本；未登记时保留未知。

# 侧栏单行标题、颜色与删除对话

基线：干净 origin/main e4591484；分支 codex/sidebar-delete-20261030。仅侧栏及其标题显示、对话删除与本机恢复依赖；记录、附件、导出、模型和其他页面布局冻结。

家长打开当前孩子侧栏，看到一行核心症状（例如“发烧”），点行尾垃圾桶，底部确认“删除对话不会影响已保存的记录”，取消回到原列表；确认后该对话消失，刷新、打开旧链接或首页不重新出现，健康日历已保存记录及原件仍能读取。

- 标题优先症状，舍弃“还没量、家长观察、当前精神好”等过程描述；最多两个短关键词，侧栏严格单行，超出省略。保留否定、既往、不确定性，不能把待确认改为确诊。
- 记录图标/文字绿，待确认文字采用现有黄色语义色；保留紧凑行尾44px删除触区，不增宽侧栏。
- 删除独立于保存记录。服务端按账户/孩子整组会话标记删除并关闭，保留正式记录及其源附件依赖；历史/详情/恢复/新输入不再访问该对话。重复确认幂等，跨账户/孩子拒绝。正在处理的会话先提示稍后重试，不抢占保存。
- 确认前无写入；确认中禁用重复操作，失败保留内容及错误可重试。关闭/切换/迟到分页不能串人或复活。删除后重新从首批读取，避免offset缩减跳过一条。
- 清理同一会话所有本机副本；删除标记阻止迟到自动保存重建。首页当前会话被删后清空为新对话；其他会话不受影响。服务端删除标记供其他设备过滤本机旧副本；保存记录不调用任何删除接口。

验收：核心关键词/单行与颜色；取消、失败重试、确认、刷新、旧链接、当前及非当前会话、多上下文、本机副本、跨孩子隔离、分页删除后连续性、正式记录/附件不变。使用本地隔离合成数据，不向正式环境写测试健康资料；main→唯一Production→实际在线只读核对。实体iPhone与用户视觉验收另行说明。

# 首页六项记录入口 · 2026-11-03

基线：main @ 8b6d5988ca674788a179dd77ae10d2e2532d2f80，工作树干净。

## 任务契约

文字输入模式的四项入口改为六项：记录症状、回传就诊资料、记载用药、喂养与饮食、睡眠、排便，顺序固定。不再先开日常菜单。六项颜色各不相同，保留原四类色，使用既有色角色为睡眠/排便区分浅粉/浅黄。完整文字、44px高度，单行横向滚动，不缩成六列或换行。

普通案例：首页改用文字→输入未发送观察→左右滑到排便→直接进入原排便表单→返回首页，保留文字和孩子归属。其余五项各直达原表单；回传就诊资料复用当前治疗复诊的就医表单，不新增上传能力或改写业务。

滑动不触发点击或提交、保存仍需原表单确认；禁用状态不打开表单。改用语音仍按现有规则隐藏快捷入口，切回与刷新保留原稿。正常/短屏、窄/宽屏可触达全部入口，标签滚动不拖动底部导航或整页。按钮静态类别继续上报已有分析元数据，不采集输入原文。其他页面、AI、记录数据结构和导航冻结。

验收：真实首页的六个顺序/颜色、左右触摸和键盘可达、全部原表单直达及返回、未发送文字/成员归属、语音切换、手机宽度无页面横溢出。构建及直接依赖回归后按现有main→Production链发布；区分浏览器仿真和实体iPhone验收。

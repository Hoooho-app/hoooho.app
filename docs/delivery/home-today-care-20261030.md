# 首页今日呵护

日期：2026-10-30。基线：干净 origin/main `e459148446a6e77376b57cfd75310358a60ef9e3`；分支 `codex/home-today-care-20261030`。

## 任务与验收契约

家长在空白对话首页，看到原每日小知识同尺寸的「今日呵护」，查看已守护天数，点击小按钮领取当天一个树芽；点击卡片其余区域进入既有呵护之旅任务页，返回或刷新仍显示同一份服务端状态。

- 保留欢迎横幅、左侧帮助卡、卡片大小和布局；首条气泡后仍整体卸载。仅替换右侧内容。
- 文案「今日呵护」「已守护 X 天」「领取小树苗」；领取后「今日已领取」。后台既有货币仍是树芽，不新增币种。
- 本次常规选择：X 为本账户累计已签到日期数，不是注册时长、余额、连续天数或已截断成就进度。初始为0，领取后加1；漏签、消费不减少。服务端从完整日期集合返回 careDays，无持久化迁移。
- 点击卡片进入 `/care-journey`，独立 button 领取，不嵌套交互元素，不触发导航；读取中/领取中禁用，失败展示原位重试，只有服务端回执才能展示成功。重试、连点和多入口领取复用既有账户+日期幂等接口。
- 原先隐藏的任务路由需定向开放 `/care-journey` 及其子页；辅助工具、家庭协作、会员与侧栏入口仍遵循当前可见性。任务页不展示跳向隐藏功能的入口。
- 守护数据归账户所有；切换孩子不重置；切换账户/卸载后不接受旧响应。过期读取不得覆盖领取回执。前后台返回和跨日重新读取同一账户时区的状态。
- 首页领取不写健康事实、对话或正式记录。现有每日任务及奖励规则不改。离线不乐观发奖；失败可再试，服务端已成功时重试不重复加分。

# 杭州 Seed TestFlight 首页验收

范围是已指定的负责人账号在完整 iPhone App 中使用现有首页。杭州发布基线来自主分支 `2ef4658`、已部署运营流水线与既有 Seed 内测。账户内的固定用例是独立验证，手机验收走首页的正常交互。

| 步骤 | 预期可核对结果 |
| --- | --- |
| 安装专用构建，启动后登录指定账号 | 容器直连 `hoooho.com`。服务就绪回执、构建标识与服务端账号授权共同生效。 |
| 首页选择虚构孩子，按住说「孩子昨晚八点咳嗽三次，没有发烧」 | 实时文字来自豆包语音。松手后，正常任务上传录音并用豆包语音生成正式转写。 |
| 等护士回复，打字更正为「前天晚上八点」 | 两轮正常对话由 Seed 2.1 Pro 处理。页面用现有对话和记录单显示更正时间，保留否定事实。 |
| 核对并保存，离开后打开记录 | 按现有保存回执核对同一事项、人物、原话、发生时间与记录详情。测试仅使用虚构资料。 |

识别任务由服务器保存模型范围。重试、后台接手和后续整理沿用所属范围。ASR 失败保留录音，成功的转写可在重试时复用。暂停、撤销、迟到结果和保存幂等继续遵循当前任务版本。其他账号、访客及合并账号没有内测权限。

发布前在杭州分别验证方舟对话和豆包语音的真实回执。使用已配置的方舟试验密钥及独立语音服务凭据。服务开关只在验证成功后启用。使用 GitHub Actions 的 Seed 构建选项，核对 Apple 处理、内部测试组和实体 iPhone 首页请求。验收需记录实时转写、正式转写、对话、记录单与总等待的回执及耗时。

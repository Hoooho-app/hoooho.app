# 专业记录能力库与 Banner 介绍

基线 main `948327cf9abb9217f6302c3a7660fe6d99a18abb`；隔离分支 `codex/recording-capability-cloud-20261102`，开始时工作树干净。

## 任务与范围

为家长提供长期可用的家庭/儿童健康记录员；为管理员提供能核对资料、授权、运行接入与评测证据的能力后台。承接本次两份岗位清单（儿童门急诊30项、高级医学记录42项），逐项保留，不能用书目数量或测试通过冒称已完整掌握。只修改能力数据/服务、必要AI上下文接入、运营后台新入口和三个现有Banner的点击说明。不恢复隐藏健康业务、不改原护士素材、不改用户记录归属/保存协议、家庭统筹独立项目及其他首页改动。

## 普通完整案例

家长在首张横幅点击→读取同源公开能力摘要→底部抽屉展示原护士图、简短职责、真实资料规模及查看来源→关闭回到同一张；轮播暂停，草稿不变。家长描述孩子昨晚咳嗽、今天没测体温→原护理问题选择链路接收相关已许可记录方法，方法仅约束如何整理，不能成为孩子事实→原核对、保存与事实引用继续工作。管理员进入`/ops/capabilities`→查看完整目标、许可资料原文及来源→用合成文本试检索→运行规则评测并取得持久回执→刷新可再次查看。真实模型语义验证、临床审阅各自独立标记，绝不由规则测试替代。

## 数据与状态

- 来源身份、URL、原作、作者/编者、许可、选取范围、正文SHA256、获取时间、可用状态是一份权威目录。已授权选段、仅链接、待购/授权、不可用于本角色分别统计；不把章节算作教材套数。
- 只从固定许可来源导入；导入工具不接受任意URL、运行服务不主动抓取URL，不产生SSRF通道。无授权的商业教材保留目录和缺口，不复制全文；没有导入成功回执不计入存量。
- 许可原文为检索/审核资料。给模型的可用记录方法单独维护，具有来源摘录和适用范围；仅用于信息采集/沟通/忠实整理，非诊断、治疗、剂量或分诊标准。知识与用户事实分开，不进入患者事实引用ID。
- 全部72项目标标明家庭记录适用/临床操作或医院管理参考；运行接入、方法评测、真实模型和临床审核分开。不得由管理员一键把待建设状态改成掌握。
- 管理检索不保存查询原文；评测仅用内置虚构数据，不写用户记录、不调用付费模型。回执含知识版本与方法版本，版本不匹配显示历史回执。
- 公开接口仅返回职责、已导入规模、来源与能力状态，不暴露管理员记录和内部日志；管理接口沿用运营专用账号鉴权。

## 恢复/并发/验收

抽屉请求失败可原位重试；关闭取消请求，迟到结果不重新打开；多次点击只开一个抽屉，返回/ESC/遮罩关闭，键盘聚焦和滚动锁沿用共享组件，减少动态效果保留手动入口。保留原6秒/560ms轮播，抽屉关闭后从原张重新计时；切换成员或首气泡卸载不丢草稿。

检索为空明示没有命中；离线不伪造数字；服务校验文件SHA后才纳入可用数量。管理员评测串行执行，以知识内容版本绑定回执，持久化失败不返回成功，刷新恢复，旧报告不套新知识。普通账号/过期token不得访问能力管理。后台有来源/目标筛选、资料原文、检索试用、评测历史与缺口。

检查：许可与文件完整性、来源/能力身份唯一、检索范围/预算/边界/空结果、事实与知识隔离、评测内容版本/并发/持久回执、公开与管理员权限、前台三张抽屉/失败/轮播/返回/320-430宽度；相关AI回归、客户端检查和生产构建。真实模型与临床能力不因这些测试通过而声称通过。

交付遵循 main→唯一Production→SUCCESS→只读接口/资源核验；实体iPhone与主人视觉验收单列。发布回执随后补充。

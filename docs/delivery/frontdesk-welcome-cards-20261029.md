# 首页欢迎区与每日小知识

日期：2026-10-29（Asia/Shanghai）。基于 `ca5084420df924c966e93ef17449c95021791ba3`，干净分支 `codex/frontdesk-welcome-cards-20261029`。产品主人确认高保真预览后授权实现并直接部署。

## 范围与任务

家长打开当前孩子的空白症状记录对话，可先了解怎样记录或阅读当日小知识，再开始真实记录。欢迎区上大下小：保留上方欢迎语与透明护士站视频，视频缩至约 186px；下方两卡并排，左为“怎么用护护／边照顾，边记录”，使用妈妈照顾发烧女儿并手持手机的 3D 图；右为每日小知识真实标题、摘要和阅读入口，不配图、不放功能图标。出现第一条实际对话气泡后，欢迎语、视频和两卡整体卸载，不留布局占位。

保留当前 main 的自动保留、语音、附件、键盘文字分类、四底导、姓名隐私、资料核对、保存与整理链路。不改服务端、健康数据、AI、凭据、原生包或其他页面版式。仅启用现有小知识阅读路径，不恢复呵护之旅等隐藏模块；不创建 Staging。

## 完整案例与状态

1. 已登录家长为选中的女儿进入空白对话，恢复完成且无可见消息时展示欢迎区。旧对话恢复期间不闪现欢迎内容。
2. 左卡打开本地使用说明：按住说话、键盘补充、拍照附件，以及健康日历回看与一键整理；关闭或“开始记录”回到原入口，不伪造发送、识别或保存。
3. 右卡复用现有账户级每日选文，点击打开同一篇已发布文章，可返回首页。每日规则仍为本地 06:00 更新；仅一篇已发布时会继续展示同篇，不生成虚构的新文章，不触发付费 AI。存储不可用仍可读，未发布内容不进入卡片。
4. 输入文字但未发送、取消录音或取消附件选择，欢迎区保留。发送文字、语音提交或附件提交产生首条实际消息时，欢迎区卸载并暂停视频；处理失败的消息也属于对话，保留重试／移除。
5. 切页、刷新和历史恢复继续沿用原账户／孩子／对话归属；存在消息的对话不显示欢迎区。显式新建空白对话恢复欢迎区。正式记录、草稿及原件保存仍由既有真实回执判断，小知识和教程不写健康记录。
6. 视频加载失败或减少动态效果使用原透明海报；教程与知识仍可读。320／390／430px 均不横溢，长标题完整换行、摘要可截短；窄高屏允许页身自然滚动，输入和底导保持原结构。

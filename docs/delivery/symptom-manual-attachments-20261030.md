# 手动记录症状与附件

日期：2026-10-30（Asia/Shanghai）。健康仓库 `Hoooho-app/hoooho.app`，干净主分支基线 `0d19a43eab782faef3ba17c288c2f8770b58c00c`，隔离分支 `codex/symptom-manual-attachments-20261030`。旧工作区保留，新克隆不覆盖其他任务。

## 用户任务与范围

家长在「记录症状」手动表单填写当前孩子的症状、部位和补充信息，可附上照片或视频，使用右上角保存；保存后在原记录链路重开正文和附件。本页移除底部语音／拍照输入栏，不把此决定扩展到首页对话。按用户最后明确的位置，在「补充信息」与「发生时间」之间放「附件」，中央加号提供拍照、拍视频、相册三种来源，不提供文件入口。既有症状分析、时间规则、正式保存与归属保持。

普通案例：手填「左肘窝发红、发痒」→填写部位、程度→附件加号选择相册照片／拍摄视频→查看附件→右上角保存→记录正文、程度和同一原件回读。附件不能未经核对自动替换用户正文。

## 实际结果

本地生产构建、806 项客户端检查及 5 项原生桥接 Node 检查通过。新增浏览器 9 项通过，覆盖四种手机宽度的顺序／中央加号／唯一顶栏保存、三种输入及取消、PDF 拒绝、照片视频返回刷新后恢复、保存失败重试与服务端原件回读、上传失败重试／移除、原生选择取消／离开后的迟到结果，以及旧包能力回退。首页输入兼容 5 项和独立记录退出保护 7 项通过；全部使用本地合成账户与供应商替身。

`JournalRecorder` 的手动症状入口显式使用本模式；共用组件的既有视频核对、内嵌病例及 AI 草稿入口不因此删除其输入能力。新原生桥接只增加可探测的 `mediaOnly` 选项；默认首页仍为既有四源、原件字节分块和可信主 frame 边界。原生媒体模式沿用本表单既有六份／单图25MB／单视频100MB限制，不把首页的单段视频规则误用到此表单。

云端原生检查、main 集成、Production 核对及新 iPhone 包的实际回执待后续补齐；本地浏览器不是实体 iPhone 验收。

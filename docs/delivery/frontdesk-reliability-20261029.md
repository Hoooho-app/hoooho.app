## 本轮任务与验收

家长为当前选定孩子录入同一件症状观察，语音变成可靠文字，护士只追问尚未明确的观察维度；不清楚位置时可点选已有身体部位定位器。第二次追问开始可以先确认整理，核对有结构的草稿后显式保存，重开同一记录并在健康日历看到一致内容。

- [x] 语音失败可真正重试同一个任务/输入；已转写的输入不重复转写，不重复创建记录。区分转写失败、对话失败与整理失败，原录音不丢失。
- [x] 减少语音传输体积与不必要的重复读取/后台整理；测量本地准备、恢复与调用阶段，不能把供应商模拟时间宣称为线上耗时改善。
- [x] 新护士回复出现或内容更新时自动进入可见区域；恢复阅读位置本身不触发提交或保存。
- [x] 位置不明确时提供既有部位选择器；选择、取消、暂不确定、切换成员均遵循现有归属和草稿规则。
- [x] 不重复询问已回答或已明确不知道的同一观察维度；保留问题/回答关联，不把不知道当作没有症状。
- [x] 合适的观察问题使用既有题库选项；提供“暂不确定”，不强迫家长猜测或自诊。
- [x] 已回答的维度显示进度；“已排查”只表示本轮询问已完成，不表示排除疾病；未知显示“暂无法确认”。
- [x] 第二次追问起在当前护士问题下持续提供蓝色整理文案与绿色文字“确认整理”；不使用大块按钮，不自动生成或保存。仍在转写/处理、对象未确认、旧版本确认不得生成。

## 普通案例与自然分支

合成例：描述“胳膊出现小红点”，回答“没有抓挠；洗澡前没观察过”，随后表示“说不清具体位置”。护士不再次比较洗澡前后；部位可点选或暂不确定。第二个问题下即可确认先整理，草稿分组列出已知与未知；其后继续补充、更正时旧生成确认失效，旧事实不得复活。保存成功才显示真实回执，聊天/日历同一记录一致。该例不代表医学评估通过。

| 分支 | 下一步与不变量 |
| --- | --- |
| 转写超时、点击重试、回执丢失 | 复用同一任务/输入/原件；明确重试命令，不能把幂等 POST 的失败快照当重试；已转写检查点复用 |
| 回答未知、改问法重复 | 记录该问题已无法确认，不重复索要同一答案；新事实或用户主动更正仍可更新 |
| 点选、取消、双击与对象切换 | 取消不产生健康事实；确认只提交当前成员的实际选择，重复点击不重复输入 |
| 第二问先整理、继续补充与并发 | 生成确认不等于保存；处理未完成不能确认旧快照；继续补充保留事实并撤销旧版本生成授权 |
| 整理失败、没有可靠结构化结果 | 已确认事实按来源分组，明确尚待核对；不把猜测、护士问题、咨询句或整段聊天当作结构化成果 |
| 刷新、退出、返回、迟到结果 | 恢复同一成员/事项与未发送输入；旧响应不覆盖新输入，读取进度不重复供应商调用或正式写入 |

## 已取得的证据

录屏观察：重复询问观察前后变化；位置不明确未呈现选择器；回复落在视野下方；记录内容串接了多轮原话。录屏多条语音最终转出文字，不能据此判定所有语音失败。

Production 只读日志：2026-10-29 00:16（Asia/Shanghai）一次 482,764 字节 WAV 请求在约 60 秒时 `ASR_TIMEOUT`，请求体发送完成在约 54.7 秒；00:27 一次 `professional-summary-generate` 被中断。源码中生成卡在无可用结构化结果时回退全部原话；首页“重试这条消息”重复幂等入队 POST，而真正重试是独立 commands/retry。上述机制与观察对应，其他具体失败仍以回归和阶段日志核对。

程序测试使用明确标注的合成供应商，保留真实持久层和浏览器。此前真实模型调用预算已用尽；本轮不擅自追加付费调用或 Production 测试健康数据写入。实体 iPhone、真实供应商语义与产品主人验收分别报告。

## 修复与验证记录

- 重试：失败输入使用原任务的 `retry` / `resume` 命令，复用已成功的转写检查点。点击回归又发现重试会写出“自己承接自己”的对话关系；已禁止这种写入，并让历史自引用不再隐藏最新对话。增加失败→重试→刷新→不重复 ASR 的完整反例。
- 性能：大于 64 KB 的 WAV 先在服务端转为 16 kHz、单声道、48 kbps MP3，仅改变发送给 ASR 的副本。真实 15 秒 PCM 编解码例从 480,044 字节降至 90,765 字节（约少 81%）；不是线上耗时承诺。追问阶段只执行一次对话分析，用户确认整理后再执行完整提取；浏览器调用计数验证了这条边界。IndexedDB 草稿读取限于当前账号/成员的键范围，轮询复用同版本原件，避免反复读取全部媒体。
- 追问：保留问题和答案的真实来源，已回答/未知的相同观察目标不换词重问。精神、进食、活动、瘙痒与疼痛等仍是不同目标，不因同属一个展示分组就一并跳过。“没有看到抓挠”属于已回答，不等于没有观察。
- 呈现：新的护士回复进入可见区域；位置题和位置不明答案呈现已有定位器；选项确认只产生一条当前成员输入。第二问显示蓝色整理文案和绿色文字确认；可继续补充，不自动保存，也不强制弹窗中断对话。草稿依可靠事实和问答维度分组，未知单列。
- 一致性：已保存记录复用健康日历的 `JournalRecordDetail`，同一记录 ID、内容与原件；共同使用 `RecordNarrative` 展示结构。前台编辑继续使用既有版本校验与草稿恢复，防止打开一致详情时丢失编辑流程。

本地已通过：受影响服务端测试 225 项；客户端测试 789 项（Asia/Shanghai）；完整构建及资源/安装配置检查。浏览器使用真实 Chromium、真实录音/编码与真实持久层，供应商响应为合成；四种手机宽度（iPhone SE 模拟、320/390/430）完整点击回归 80 项全部通过；故意延迟详情加载后立即返回的专项检查另有 4 项通过。已修正页面尚在加载时旧前台拦截器误挡返回的问题，允许回到已持久化的原对话地址。部位选择/暂不确定属于补充输入，不得误答正在询问的其他维度；取消不提交。

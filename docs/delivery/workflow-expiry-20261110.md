# 工作流节点的到期日

管理员打开工作流，直接在对应节点看日期和按北京时间更新的剩余天数。节点详情可打开原平台核对，续期或换证后填写新日期，也可清空暂时无法确认的日期。保存失败保留输入，其他标签页先改过同一项时提示重新核对。费用、续费和发布仍在原平台办理。

- 域名注册、ICP备案关联的公安联网备案数据码、ECS 服务期、边缘和源站证书分别记录，不能相互推断。自动续费或证书轮换后以平台新回执为准。续订日与停服日分开。
- Apple 团队会籍、分发证书、描述文件和 TestFlight 构建分别记录。项目之间不串签名材料；上传、分组、真机节点引用同一项目的同一版本和构建。没有构建号时留空。显示平台核验的构建不代表登记进度或确认真机已安装。
- 没有可核验日期时显示「—」。日期来自服务端私有回执或管理员更新；只保存日期、时间（平台明确提供时）、核对来源和必要的构建标识。平台密钥、证书文件、密码和备案数据码均不写入。
- 验收：管理员可在原节点核对并维护；续期后关联节点同时更新，刷新后保留；跨北京时间零点时正确进入临期/过期，空值不当作正常；切换项目或选择另一构建不沿用日期；其他账号不能读取或写入。

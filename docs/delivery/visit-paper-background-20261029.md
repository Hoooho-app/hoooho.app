# 就诊情况单提示与全屏纸张底色

日期：2026-10-29。基线：`c28bfc054cce8013e842c8989551aaa163789b1a`，干净 `origin/main`；隔离分支 `codex/visit-paper-background-20261029`。

## 用户任务与验收

家长打开已有就诊情况单，直接阅读孩子资料与本次情况，再展开章节、编辑、返回或导出。即使原选照片失效、原选症状不可用，阅读页也不展示后台诊断警告，不占位、不要求先处理这些提示。

- 删除情况单阅读页对 `state.warnings` / `report.warnings` 的整块警告渲染；后台仍负责资料筛选、权限与版本检查，不自动替换原件。
- 页面根层、页头、底导及上下安全区沿用现有纸张页底色 `--hoho-color-page-background`（`#f4f2ed`）；覆盖首页、健康日历、孩子档案、情况单与从它打开的页面。
- 保留必要的加载、保存失败和重试反馈；不把诊断提示改放弹窗、toast 或其他占位。
- 不更改记录、草稿、API、选择范围、导出内容、导航结构及其他页面的卡片和内容设计。

普通案例：已有报告带失效照片/症状的诊断信息 → 进入情况单 → 目录下直接显示孩子资料 → 展开目前情况 → 打开编辑再取消 → 返回报告 → 刷新后仍无诊断卡片。信息只读呈现的删减不会改变服务器事实、报告版本或原选择。

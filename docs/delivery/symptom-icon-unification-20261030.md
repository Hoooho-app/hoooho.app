# 症状标识统一为医疗十字

日期：2026-10-30（Asia/Shanghai）。基线 `main @ 166df3f931c6f5c38213c464a4c8269549d94f53`，隔离分支 `codex/unified-symptom-icon-20261030`。

## 范围与案例

家长从底导「症状记录」进入，打开手动记录表单，看到「症状描述」的空心医疗十字；保存或返回已有记录后，在日历分类、症状卡、跟进页和就诊情况的当前描述中看到同一标识。当前导航选中时沿用实心，其他默认空心，返回或刷新仍由实际路由与业务选择决定，不另存图标状态。

本轮只替换现有症状标识；不新增图标到原本纯文字的入口，不改变导航、文字、布局、点击、草稿、校验、保存和原件归属。不调用真实 AI 或写正式健康资料。部位定位人形、就诊听诊器、用药药片及其他独立语义维持现状。

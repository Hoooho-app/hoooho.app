# 首页记忆库横幅与无控件轮换

基线 `e459148446a6e77376b57cfd75310358a60ef9e3`，干净隔离分支 `codex/frontdesk-memory-banner-20261030`。

家长打开空白首页，先看原护士欢迎张，8秒后沿用既有马赛克切到记忆库张；移除“暂停”及圆点，不增加替代可见控件。新张标题通栏“记忆很长，慢慢记。”，下方档案图在左、短句在右：“记了很久，也只是记忆库的一小段。存好的记录，随时回看。”用长期记忆库作记录积累的视觉隐喻，不宣传AI无限上下文、永久不忘或自动读取所有历史；本轮未实现/变更AI检索、存储、数据或权限。

保留输入/未发送草稿/录音、后台时暂停，停止后从完整张重新计时；悬停与键盘聚焦欢迎区域可暂停阅读，焦点不加可见按钮。减少动态效果保持静态欢迎张。原图或第二图异常不引入空白轮换。第一条气泡出现时全部卸载并清理定时器，取消录音/附件不作为消息。文章/帮助及孩子归属、草稿、保存规则不变。

尺寸必须保持既有满屏适配，两张切换不挤动下方卡片。短屏/长屏文字与图片不重叠、标题不压正文，人物及档案图contain；特殊大字号/键盘仍可滚动。

范围只含横幅组件/局部CSS/规则/契约和对应浏览器测试；复用现有3D档案插图，无新资产、依赖、后台或原生包。验证无可见控件、两张不同编排、停留/马赛克/聚焦暂停/输入暂停/后台模拟/坏图/减少动态效果及原欢迎流程。按main→唯一Production→SUCCESS→health/首页/JS/CSS只读核验交付，不写正式健康数据或运行付费验收。截图与Chromium模拟不代表实体iPhone或主人验收。

# 档案摘要与精简孩子顶栏

基线：origin/main `8b6d5988ca674788a179dd77ae10d2e2532d2f80`，隔离分支 codex/archive-summary-20261103，初始工作树干净。

## 任务契约

家长点底部“档案”，在“基本资料”标题下、“身份与出生背景”入口前直接看见当前孩子的年龄、血型、身高与体重；通过原身份页或生长页补全资料，返回后反映已保存内容。信息区使用清晰数值网格，区别于下方可点击的入口列表，不新增编辑入口或资料存储。

- 底导与档案根页标题统一“档案”；现有路由、底导固定高度、入口列表保持。
- 顶部孩子缩略信息只留头像和姓名，移除年龄、箭头，保留点击切换孩子。共享的记录对象顶部资料也只留头像姓名。首页小树苗保留原间距与点击功能，随姓名组收短自然左移。侧栏和选择面板中的完整年龄不受此缩略规则影响。
- 年龄由现有出生日期格式计算；血型/RhD来自当前成员资料；身高体重复用现有生长数据摘要规则，按当前成员分别取有效值及对应测量日期。仅有待确认数据时显示待确认，不把刷新时间当测量时间。
- 未填写、读取中、读取失败分开显示；失败可重试，不把失败说成未填写。切换孩子/账号用key重建摘要并取消旧请求，迟到结果不能串入另一人。返回重开、窗口聚焦和既有数据失效通知触发重读；不写健康资料，不重复保存。
- 不修改AI、API、存储、记录表单、原生代码或其他模块；示例验证仅用隔离合成账号。

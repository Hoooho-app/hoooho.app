日期：2026-11-03（北京时间）。基线：干净 main `3fae7dbfac327b1a27b403c8afb7a1789c8710de`；隔离分支 `fix/bowel-record-conventions-20261103`。

## 任务与验收契约

家长从首页「改用文字→日常→排便」进入，为当前孩子选择实际观察到的形状、颜色，按需补充分量、耗时、过程、血迹及其他观察，添加照片、核对时间，保存后返回首页，能在健康日历查看结果。

本轮只统一排便表单：复用其他手动页的白色分组、页头返回/保存、共享记录时间行和末尾每天设置。补充信息默认折叠，右箭头展开朝下；分量、耗时改为与过程一致的直接选项，再点取消，不默认首档。附件为标题同行加号及原有缩略图、删除和重试。形状与颜色及所有原有选项保留，不变更健康数据结构、服务端、AI、其他记录页或原生包。

| 场景 | 规则与验收 |
| --- | --- |
| 普通完整案例 | 多选形状、单选颜色，展开补充，选择量/耗时，再核对记录时间并保存；真实本地API回读与所选字段一致 |
| 更正/撤回 | 所有选项可再次点击取消；补充折叠不清空已选值；未填写量/耗时不保存虚构首档 |
| 返回/重开 | 沿用原记录器导航与按孩子保存的表单草稿、照片恢复；不在返回时正式保存 |
| 失败/重试 | 原内容保留、错误可见，可继续保存；不能提前清理草稿或照片 |
| 保存等待/重复操作 | 单次保存进行中禁用返回及编辑、上传、删除；同步锁避免重复提交，实际成功后才清理草稿、关闭表单 |
| 移动页面 | 320/390px 下只有正文滚动，页头固定，无水平溢出；选项可达且文字可读 |
| 下游 | 保持原 journal.bowel / occurredAt / 附件归属、详情编辑与日历排序；无生产健康数据测试写入 |

# 首页护士半身图与小屏适配

基线：`0d19a43eab782faef3ba17c288c2f8770b58c00c`，干净分支 `codex/frontdesk-nurse-mini-20261030`。日期：2026-10-30（Asia/Shanghai）。

## 用户任务与确认范围

家长在 iPhone mini 打开空白首页，看清欢迎文案、护士和两个内容入口，再开始记录。首页欢迎视频改为既有护士站右侧黑发护士的透明 3D 半身图：口罩、眼镜、一手病历夹、一手笔。文案不改内容，只限制段落宽度、自然换行，让右侧形象有独立空间。收紧原 300px 欢迎区与卡片留白，图片使用 contain 完整展示，不裁人物、不让输入栏盖住卡片。

保留左侧妈妈持手机照护图与教程、右侧真实每日小知识和阅读链路，以及第一气泡后整个欢迎区移除的规则。原视频文件和整理过程中的视频保持；不改对话、保存、AI、健康数据、导航、权限、原生包或其他页面。

## 完整案例与分支

空白对话恢复完成后，先显示护士半身图和两卡；点教程再关闭不发消息，点知识文章可返回。输入未发送、取消录音或附件仍保留欢迎区。首条实际消息出现后全区卸载，已有对话恢复不重现，显式新对话再显示。所有记录持久化仍沿用原链路，本轮没有新写入或异步工作。

短屏按页身实际可用高度压缩欢迎区、图像和非必要间距，保留可读文字及触摸入口；iPhone mini 的完整可用高度与浏览器工具栏占用分别模拟。极小高度及打开系统键盘时允许页身滚动，图片本身仍完整，不裁剪或缩小底部输入／导航。大字体自然增加内容高度，保留滚动兜底。图片不可用时保留可读替代文字与两个功能入口。

- 首页没有视频、canvas 或播放器监听，只加载清晰透明护士图；原视频及处理中用途不变。
- 段落右边界与护士图不相交，内容不省略，窄屏自然多行。
- 375×812、375×724、375×667 与 390／430 常规屏核对完整图像、卡片到输入区间隔；320×568 验证可滚动及无横溢。
- 教程、真实知识文章、未发输入、第一气泡收起、失败、恢复和新对话继续可用。
- 当前构建、客户端检查、媒体完整性和移动浏览器专项通过；按既有 Production 单环境链发布，精确提交 SUCCESS 后只读核验 health、首页与 JS/CSS／图片。移动模拟不等于实体 iPhone 已验收。

旧欢迎视频的播放／循环浏览器场景不再属于首页验收，以静态图完整性与小屏几何验收替代；原视频文件完整性检查继续保留，不为旧测试恢复已替换的视频。

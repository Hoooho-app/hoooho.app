# 首页输入与自动保留

日期：2026-10-29（Asia/Shanghai）。基线 `3784d7a`，干净 `origin/main`；隔离分支 `codex/frontdesk-input-simplify-20261029`。

## 任务与范围

家长在当前孩子的首页连续记录情况，随时切到日历、档案、查找或历史，再回来继续同一对话。输入、录音原件和任务回执沿用现有按账户/孩子划分的本机草稿与后台对话，不要求切页时再次选择保存。保留原始内容不等于产生正式健康记录，正式保存仍以现有服务端回执为准。

本轮用户授权五项：首页切页不弹草稿确认；无文字的语音处理中只显示 loading；失败操作为同行的「重试」「移除」；补全进度为圆点/文字/连接线，已完成项呈绿色；移除网页附件选择弹窗，直接使用系统选择，iPhone 原生菜单提供相册、拍照、拍视频、文件四项。其他记录表单、AI 理解、事实规则、保存/导出和背景方案不扩展修改。

## 普通案例及分支

| 场景 | 预期与保留依据 | 责任与验收 |
| --- | --- | --- |
| 输入「昨天脸颊有点红」，发送后再输入未发送补充，切孩子档案/快速查找后返回 | 直接切页，无确认/清除；原对话、未发送补充仍在，侧栏能打开当前对话 | SmartRecordWorkspace、SideDrawer；真实浏览器本地合成账户，切换、返回与刷新 |
| 录音松开、上传/转写仍在进行时切页 | 已有稳定消息 ID 和原录音先保留；已接收任务继续后台处理；未接收原件返回后可重试，不自动重复业务写入 | 复用 captureDraft 串行写入、beginCaptureFinalization 和任务回读；浏览器延迟回执及录音中切页 |
| 尚无转写文字 | 用户气泡只显示带无障碍名称的 loading，不显示麦克风和「语音消息」；转写文字存在时继续显示实际文字 | 消息渲染；延迟合成 ASR |
| 转写失败、重试/移除 | 两个按钮同行；原条消息/原件重试不重复；失败与取消区别保留 | 现有 retryTurn/discardTurn，移动宽度与原 ID 核验 |
| 补充或更正关键资料 | 使用原有 checks 的状态，不自行推断完成；answered 的圆点和文字变绿，missing/uncertain 保持中性色，不显示「已获得/待补充」 | FrontDeskQuestionTools、既有 tokens；真实浏览器及已有数值/部位用例 |
| 点相机并取消，或权限拒绝 | 网页直接调用系统 file input；新原生包直接显示四项系统菜单，取消不建消息、不清输入；只在选拍照/视频后请求相应系统权限 | DialogueComposer、NativeBridge、NativeAttachments；网页 chooser / 原生合成 UI 与权限测试 |
| 选择照片/PDF/单段视频 | 沿用当前 12 份/15MB 图片资料及单段 100MB 视频限制和既有核对链路；选定原件只传回发起页面，切账户/孩子后不得串写 | 原生临时文件与分块读取，客户端按归属接收；原件字节与取消、过期/错误测试 |

原生四项菜单只在安装包含新能力的 iPhone 包后生效；旧包和普通浏览器使用系统本身的照片/视频/文件入口，网页无法修改 Safari 自身菜单文案或强制其为四项。新增能力采用主 frame 与精确可信源校验；不改变其他 file input 的系统行为。临时选定文件在成功、异常释放或过期后清理，不进入公共构建产物。

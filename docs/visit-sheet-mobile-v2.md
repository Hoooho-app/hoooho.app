# 就诊情况单：手机版九章交付说明

## 范围与实现

本轮以 2026-09-26 上传的《手机版就诊情况单 Codex 完整执行提示词》为最高产品依据。读取了产品方案、交互 HTML。其引用的交互总览、报告示例、使用说明及 demo_data.json 未取得，未使用其预设数据或历史测试结果。

前台护士站与健康随记共用 `/visit-summary`，旧 `/visit-summary/:eventId` 保留且校验当前孩子。首次读取没有已保存报告时直接生成；无范围向导。旧分享组件与已有分享 API 不变。

真实资料 → `VisitSheetService.collect` 成员权限过滤 → `buildVisitSheet` 确定性事实整理 → 同一持久化快照 → 九章阅读、图表、完整来源、HTML、AI 文本与打印。未新增医学诊断、治疗建议或模型推断。

新增 `GET/PUT /api/members/:id/visit-sheet`（需当前账号权限、禁止缓存）。PUT 使用 `expectedVersion` 和 `requestId`；同一报告 ID 递增版本、保留历史。数据保存在现有数据目录的 `visit-sheets.json`，已纳入游客账号合并及账号删除。无数据库破坏性迁移。旧记录不重写、不删除；可回退应用代码，新增文件保留。

症状按发生时间优先、录入时间其次、ID 稳定排序；正文标明实际纳入范围。有关联字段时按原关联纳入处理。手动焦点不随普通更新变化。自填无匹配资料时不保留旧症状图。病程、统计、引用共同重算，其他资料仍可检索。

## 复现与验收

```sh
npm run test:client
npm run test:server
node --test server/visit-sheets/*.test.mjs
npm run build
npx playwright test --config tests/visit-sheet/playwright.config.ts
node tests/visit-sheet/live-smoke.mjs https://hooohoapp-staging.up.railway.app
node tests/visit-sheet/live-smoke.mjs https://hoooho.com
git diff --check
```

本地 E2E 使用独立临时目录和明确虚构资料，不读取/复制生产数据。截图、离线文件在 `test-results/visit-sheet-*/`；线上 smoke 只创建隔离的合成账号，验证两个入口、真实保存/再读取、九章及导出，随后只删除本次创建的来源、事件和孩子。账号及报告审计仍保留，不绕过账号身份验证进行清理。

故障注入测试禁用测试浏览器的 Service Worker，以便网络拦截能实际生效；真实发布 smoke 保留生产 Service Worker。仓库未提供 lint 命令，lint 为 N/A；不等同 TypeScript 检查。

## 设计与冻结边界

复用现有绿色 token、BottomSheetSurface、HohoButton、现有记录编辑组件。新增 FactCharts 是共享设计系统组件，图例文字和数值清单不依赖颜色或悬浮。未改会员权限、全局导航、记录创建业务、守护任务执行/归档/删除规则、护士动画和媒体。

固定快照不能实时反映其他页面刚发生的变更；重新进入核验并提示更新。历史资料字段缺失时明确未提供，冲突/待核对保持来源标记。HTML 下载意味着文件准备好，不表示用户已完成保存。

# 就诊情况单：四卡片版实施与验收

依据：最新 `Hoooho_Visit_Codex_Prompt.md`、交互稿、交互地图及截图。最新四卡片阅读结构覆盖 v5/v6 九章铺陈；此前 P-001—P-026、A-01—A-54 的数据正确性、安全性要求仍保留。历史验收在 `visit-sheet-v5.md`，不能当作本次运行证据。

## 范围和数据链

沿用当前应用 `/visit-summary`、事件入口、护士站和健康随记两个入口，不另建项目。首页与记录症状页不改结构。视觉沿用症状记录页的真实设计变量、头像、图标和焦点/滚动组件。

当前账号/孩子 → 已有记录、档案、测量、观察、提醒及附件服务 → `report-model`、`v5-projection`、新增 `reading-projection` → 同一持久化情况单 → 四卡片、依据、编辑、更新与导出。没有把原型孩子、固定数值、模拟病情照片或本地演示状态写入运行时。测试仅用隔离合成账号、纯色图和两秒纯色视频，不复制真实医疗数据，不调用付费模型。

四卡片：本次情况默认展开；本次想问、经过与处理、完整资料默认收起。四个编辑入口独立于折叠按钮。既往、过敏、观察、提醒、体温/成长图表、就诊和完整原文仍在完整资料或处理详情中可达。

### API、存储与兼容

- 继续 `GET/PUT /api/members/:memberId/visit-sheet`；新增可选 `caseDetails` 四项报告补充，不覆写临床原记录；自填主诉可通过 `focus.relatedSourceIds` 明确选择本成员记录，不依赖文字恰好匹配。
- `previewUpdate:true` 只存服务端 24 小时草稿，不改正式情况单。`confirmUpdate:id` 检查账户、成员、旧版本、来源指纹、到期时间后提交；重复确认幂等，确认不再调用模型。源变化或其他位置保存时 409，不覆盖旧版。
- 新私有 `visit-update-candidates.json` 纳入账户数据合并/清除管理；沿用现有 JSON 事务和账户锁，无数据库迁移、Secret 或权限配置变更。
- 新 `POST /api/members/:memberId/visit-sheet/media/:draftId` 复用现有真实二进制验证、原件存储和视频转码，不触发影像 AI 作业。图片沿用照片上传。用户现有原件仍需登录授权读取，附件不是症状记录。
- `VisitPhoto` 兼容增补实际 duration/binarySize；照片和视频全量三列编号、56px 缩略图。无媒体不占位，原图保留比例并可放大；视频原件原生 controls/playsinline、不自动播放，关闭暂停并释放 URL。
- 领域指纹增加 four-card-reading-v1。已有快照可阅读但会提示需更新；更新确认保留问题、补充和主题影像选择。缺少新 reading 字段的旧快照不将计划当已执行处理。
- 首次记录日期不是实际起病日期；发生、录入、计划、执行和上传时间不互换。最新有效身高/体重分别引用自己的测量来源，缺失为“未填写”，未知不替成 0 或正常。

### 导出契约

二级整页共用范围选择：默认“本次就诊重点”，可选“情况单与完整资料”。HTML、打印与复制读取当前确认版；准备前后重新核验快照，取消、来源变化或所选原件获取失败不产出假完整文件。文本明确只有索引，不声称含原件。

HTML 为不可回写的固定确认快照，CSP 禁止脚本和网络连接，数据库 ID 转成 SRC 引用，不带令牌、私有地址、blob URL。已选图片真实内嵌；视频勾选“附带原视频”才内嵌实际字节，未勾选有清楚的未附说明。内嵌原件总量上限 80MB，原件可独立下载；现有上传限制仍为 100MB/120秒，超限明确失败。额外导出但未用于当前主诉的影像单独标识，不能冒充主诉证据。非 raster/PDF 等附件只保留索引，原件需另下载。

打印即使页面内容折叠也有完整正文、图表和对应依据；纵图打印等比限高，离线原件不被裁剪或降成占位。复制失败提供可全选文本。未通过 AI 校验的预览仍可人工修改并导出有“非已确认报告”标识的核对材料，绝不冒充已确认情况单或保存为有效事实。

最新固定快照取代此前离线可编辑副本入口；旧 `reportHtml/offlineRuntime` 保留兼容代码，当前入口不承诺离线编辑回写或本地修订。旧公共分享模块未改，不宣称已升级为新协作功能。

下表“通过”仅限所列自动化/合成数据证据；不表示临床有效性或全设备穷举。发布状态另见本次交付记录，不以旧文档的已发布状态代替。

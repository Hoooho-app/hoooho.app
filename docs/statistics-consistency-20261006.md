# Hoooho 统计一致性修复

修复统计审查确认的10项问题，并包含此前已授权的过敏全局联动补丁。基于主分支`7a1b07d`，保留已合入的首页、跟进状态及忌口卡语言功能。

## 最终行为

| 问题 | 修复后的行为 |
| --- | --- |
| 体温区间被当成实测 | 区间、约数及假设/否定表达保留原文，不计入精确测量点 |
| 同条记录多次测温漏计 | 优先读取当前有效的结构化测量事实；保留各次时间，避免再重复统计原文。显式结构化更正仍优先 |
| 用药今日进度分母失真 | 今日计划完成数/今日实际计划数为同一范围；今天补记的历史服药按实际服用时间单独显示，不扩大计划分母 |
| 旧过敏归档读成0条 | 继承过敏联动修复的嵌套归档展开、成员隔离、稳定ID及删除过滤；客户端与服务端读取一致 |
| 搜索修改后保留旧数量 | 详情保存、删除、结束睡眠等变化触发搜索数据重取，再重新计算匹配结果和数量 |
| 问AI选择与统计不一致 | 分组、总数、原始记录及附件均只统计已选择资料。调整选择后使旧预览失效，避免新数字配旧正文 |
| 成长加载时显示假零值 | 加载或首次加载失败时不宣称已保存0条；只有取得记录列表后显示数量 |
| 后台指标范围混用 | 总数、今日更新、失败及重登录均限定已启用来源 |
| 后台今日日期跟随服务器时区 | 明确按北京时间日历日统计，UTC环境也能正确区分昨日/今日；无效时间不计入且不崩溃 |
| 后台读取失败显示0 | 概览用未知值，只有成功读取后显示数字；更改来源后重取失败会反馈同步错误 |
| 反馈平均首次查看错误 | 每份反馈只贡献最早有效查看时间；新查看保存首次时间，重复查看不改变它，兼容旧状态历史与旧查看字段 |

体温统计规则的修订进入情况单指纹。旧情况单标记待更新，保留旧版本供核对；重新整理后采用修正的统计，不静默重写用户报告或导出的文件。

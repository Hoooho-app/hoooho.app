# 忌口卡语言输出

出示卡仅提供单一母语与 English 输出，移除母语 + English 选项。已有简体值 `zh` 和双语值 `en-zh` 保持兼容；新增 `en`、`zh-Hant` 和 `en-zh-Hant`，不改变原始健康记录或快照版本。

当前支持简体中文、繁体中文及英文。显式保存的账号界面语言优先，否则读取设备的浏览器语言地区；`zh-TW`、`zh-HK`、`zh-MO`、`zh-Hant` 使用繁体，`zh-Hans` 明确使用简体，英文设备使用 English 并合并重复选项。尚不支持的设备语言沿用产品简体默认值。这里使用语言地区，不通过 IP 或定位推断母语。

默认使用账号或设备对应的单一母语。卡片正文、标准食物名称、文字标记和 PNG 导出使用相同输出语言。繁体转换仅覆盖卡片固定文案及已有标准食物词表；自定义名称保留用户原文，不猜译或改写健康记录。

手动补充的英文名称优先于已有食物词表。旧双语值仅保留内部兼容，页面不再提供或默认选择；纯英文缺少任一可见食物的英文名称时显示补充入口，禁止出示或导出不完整卡片。隐藏食物不影响该检查。

访问页面、回到前台或收到资料变更通知时自动读取最新来源，沿用已有合并规则，不额外提交保存。工具栏为修改编辑、语言、保存图片三个等宽项。页面仅保留「忌口卡」标题；侧栏同步名称。共用锅具、餐具提示及其编辑开关移除，PNG 同步移除；旧快照字段保持兼容。

验证：`npm run test:client`、`npm run build`、`npm run test:e2e:dietary-card`。在线构建验收使用 `DIETARY_BASE_URL` 指向已部署环境，业务 API 使用隔离虚构数据，不写入生产健康记录；公共页面、静态资源、健康接口及 deployed commit 另行核验。

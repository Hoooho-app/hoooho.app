# 情况单五处交互修正

保留既有四卡片、工具栏和设计系统。此补丁只调整情况单的阅读与编辑交互，不改变模型、医疗原始记录或报告服务协议。

| 问题 | 修正 |
| --- | --- |
| 浏览器返回丢失编辑草稿 | 页面取消、路由返回共用保存/放弃/继续编辑提示；提示自动滚入可见区域。刷新和离开文档使用浏览器原生草稿保护。保存失败保留输入，保存途中禁止改动字段并等待结果后返回。 |
| 自定义主诉尚无来源 | 显示“尚未关联记录”，直接打开相关记录选择；仅保存家长明确选择的关联，保留主诉与原始记录。 |
| 用药资料折叠过深 | “经过与处理”直接进入独立用药详情，展开完整周历和记录依据；计划、未来、未确认与实际使用仍分开。查看原文时暂停下层页面的焦点和 Escape 处理，关闭依据后返回详情。 |
| 添加影像入口隐蔽 | “本次情况”右侧直接提供“添加影像”，复用既有上传、选择和确认流程。 |
| 更新预览是长文本 | 更新草稿按卡片呈现，首先显示新增、有变化和不再纳入的资料；原文按需核对，版本号与来源编号不作为默认正文。来源编号或更新时间改变不冒充病情变化。 |

## 验收清单

- [x] 整理时用「嗯，我了解了，我整理一下。」口语接话，配原护士站小视频与「整理中」；移除接收→整理→核对流程条。
- [x] 整理完成后先按实际缺失信息追问，追问阶段不展示「整理后的描述」；已有回答不重复问，不知道、没注意或要求先记录时停止。
- [x] 补足「身体有点冷」观察主题：先分清孩子自述或家长触感/观察，再补充开始与持续过程；不推断发热、低体温或病因。
- [x] 普通追问最多三轮；补充绑定同一上下文，保存仍需用户操作。
- [x] 「立即保存」「核对记录」同一行、等宽、同等 secondary 样式，均有边框。立即保存使用原保存链路；核对进入现有可编辑结果。
- [x] 复用原视频、V2 组件和主题；暂停、失败、重试、原件保留与减少动态效果沿用原边界。

范围仅含护士对话、相关护理观察检索与抽取指令及必要回归测试。沿现有症状/日常等类型归类，不新增「知识」归档模块，不修改健康事实持久化协议。

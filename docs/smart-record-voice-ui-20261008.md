# 智能记录：语音操作区与对话身份整改（2026-10-08）

按产品负责人确认：标题与症状表单入口统一为“智能记录”，使用同一个护士帽图标。默认语音模式只突出一个录音操作及“改用文字”；主动切换文字后才出现输入框和发送。首页显式“打字聊”仍直接进入文字模式，显式“和护士说”仍在用户点击后尝试开麦，收起、重开和刷新不自动开麦。

护士消息使用首页原护士视频的金发护士静态头像，用户消息使用记录者昵称的拉丁/拼音首字母（刘 → L，无可用昵称 → U）；不使用孩子的姓名或泄露登录邮箱。头像素材从现有视频第一帧提取，动画与首页素材保持原样。

移除人工勾选更正。用户可以自然说“不是身上，是脸上”，沿用现有模型上下文理解与原话来源校验。模型指令补充：只更正改口的维度，保留此前有效症状、数量和不确定性；含义不明时澄清，不替家长作情绪判断。旧的已存更正来源仍兼容，不改历史记录与结构。

语音连接、聆听、回复、暂停与断线均有对应提示和主按钮。自动播放被阻止时，关闭并解绑麦克风；回复结束不能误切回“正在听”，必须经用户点击恢复。发送文字先保存到现有待同步原话队列，等待上一段语音同步完成，收起不会丢失已发送原话。

“整理到表单”返回原症状字段核对，不直接保存；“收起”暂停语音并保留对话。普通语音仍只写入症状描述，原有人工修改保护、专业备注和确认保存路径不变。

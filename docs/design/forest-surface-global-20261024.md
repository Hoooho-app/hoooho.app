## 本轮颜色与渲染规则

| 用途 | 颜色 | 执行方式 |
| --- | --- | --- |
| 全页与安全区 | `#09231B` | `canvas`／全局页面背景，无纸张噪点 |
| 画布正文 | `#F3F0E7` | on-canvas；次级 `#C1CDC3` |
| 浮起的内容面 | `#FCFBF7`／`#FFFEFA` | 沿用圆角与阴影层级；护士视频所在面为纯白 |
| 浅面内正文 | `#273332` | ink；次级 `#5E6961`，弱文 `#657068` |
| 主操作 | `#F3F0E7`／`#112F29` | action 填色／文字；浅面内补 `#71806E` 轮廓 |
| 遮罩 | `#05120E` | 独立 scrim token，不能再借用正文色 |

`forest.css` 负责现有浅色表面的文字上下文，避免旧页面在白卡内继承浅字。新自定义浅面可使用 `data-hoho-surface="light"`；透明页面根、透明页头与滚动容器不能登记为浅面。新增组件优先使用现有 V2 Surface／Button。

`link` 是随表面变化的前景色，`primary` 继续用于图表、状态和现有分类填色，不能把两者混用。表单页头深绿底配浅标题，白圆返回按钮则使用深绿图标。正文与关键按钮在浏览器实际合成背景下按至少 4.5:1 检查；焦点仍可见，高对比设置保留。禁用控件允许降低强调度。

独立情况单 HTML／打印保持浅面深字基础，不引入站点 `forest.css`。开屏三页已确认的插画资产与明暗分镜保持原样，仅外围延续绿底。

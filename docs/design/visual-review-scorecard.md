# Visual review scorecard

Score each applicable dimension from 0 to 5 and cite a screenshot, DOM observation, or implementation file.

| Dimension | What 5 means |
| --- | --- |
| Information hierarchy | Importance is immediately legible without hiding necessary detail. |
| First visual focus | One task-relevant focal point leads the view. |
| Typography | Roles, weights, line heights, wrapping, and data alignment are deliberate. |
| Spacing precision | Rhythm is consistent and content density suits the task. |
| Alignment precision | Text, controls, dividers, and repeated structures share clear anchors. |
| Color control | Semantic color and Hoooho green are restrained, consistent, and accessible. |
| Icon unity | One coherent icon language, size system, color logic, and accessible labeling. |
| Component consistency | Shared behavior and visual grammar without flattening page identity. |
| Brand recognition | The result is recognizably Hoooho rather than a generic health/SaaS template. |
| Emotion and trust | Calm, clear, warm professionalism without coldness or childishness. |
| Mobile finish | Purpose-built composition, touch ergonomics, safe areas, and no overflow. |
| State completeness | Loading, empty, error, success, disabled, overlay, and long content are designed. |
| Motion continuity | State changes feel continuous, stable, and reduced-motion safe. |
| Readability | Chinese and numeric content remain readable at real mobile sizes. |
| Accessibility | Contrast, focus, semantics, zoom, and non-color cues support use. |
| Memorability | One restrained product-specific signature survives without decoration overload. |

## Scale

- `0`: absent or unusable.
- `1`: severe systemic failure.
- `2`: materially below release quality.
- `3`: functional baseline with visible inconsistency or generic treatment.
- `4`: coherent, polished, and release-ready with minor gaps.
- `5`: exemplary, evidence-backed execution for this product and state.

The release target is no dimension below 3, critical usability dimensions at least 4, and an average of at least 4 for the reviewed scope. A high average cannot hide a failing accessibility, readability, mobile, or state-completeness dimension.

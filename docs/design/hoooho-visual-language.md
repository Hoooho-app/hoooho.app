# Hoooho visual language

## Character

Hoooho is gentle, trustworthy, lucid, light, restrained, alive, modern, and precise: a contemporary professional triage desk that is not cold. White is the primary space. Hoooho green is a life signal, confirmation, and brand cue—not a decorative wash.

The signature is the restrained three-point continuous health trace already defined by Design System V2. Use it at selected brand or continuity moments; repetition turns identity into decoration.

## Foundation

`docs/hoooho-design-system-v2.md` and `src/styles/tokens.css` are the implementation source of truth. Prefer semantic tokens and existing components. Ordinary content is flat or quietly bordered; elevation belongs to meaningful separation and floating layers. One primary action leads each view.

Typography is information architecture. Chinese body text remains readable and calm; headings use disciplined weight rather than oversized display treatment. Secondary text is compact but not faint. Numbers that users compare use stable alignment.

## Composition

Use hierarchy, grouping, dividers, alignment, and rhythm before decoration. Avoid nested cards and equal visual weight for every module. Preserve distinct page jobs: the event list emphasizes chronological scanning, while event detail emphasizes exact facts and changes.

## Motion and state

Motion connects state and preserves continuity. Feedback is fast, ordinary transitions are calm, and complex transitions remain bounded by V2 tokens. Never introduce unexplained scaling, long frozen keyframes, content flashes, or layout jumps. Honor reduced motion.

## Responsive behavior

Mobile is primary. The visible development preview remains iPhone SE portrait; 375, 390, and 430 px checks run independently. Keep the sidebar navigation model. Mobile must be composed for touch and reading, not rendered as a shrunken desktop page.

## Anti-template rules

Avoid generic SaaS dashboards, grids of equal white cards, card nesting, decorative pills, meaningless hero blocks, ubiquitous gradients or glass, large mint backgrounds, random colored icons, emoji as formal icons, conflicting black/green icon systems, oversized secondary copy, childlike roundness, empty space without focus, and novelty that changes mature interaction behavior.

A visual upgrade is not accepted when its substance is only color, shadow, radius, heading size, or whitespace.

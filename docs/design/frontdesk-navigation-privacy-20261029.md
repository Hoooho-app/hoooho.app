# 首页、导航与侧栏：2026-10-29 产品决定

基线：`40e6907`，分支 `codex/frontdesk-privacy-navigation-20261029`。本次按用户确认的高保真方案落地；不以历史视觉冻结规则阻止本次明确授权的首页和导航调整。

## 范围与固定规则

- 首页标题和第一个底导恢复为「症状记录」，主入口「按住记录症状」。其他底导为「健康日历」「孩子档案」「一键整理」，不增加「我的」。四项从侧栏移出。
- 头部为菜单、症状记录、脱敏孩子头像/姓名/年龄、搜索；移除三点菜单。欢迎语「今天怎么样？」「我是档案员护工。」不包含孩子姓名。使用现有护士站视频，无极光、日期海报、说明口号或新增素材。
- 默认语音不显示分类。键盘模式展开症状、用药、日常、治疗复诊四个已有入口；日常浅杏、用药浅紫，其他沿用浅绿/蓝。切换方式保留文字和附件，不自动提交/保存。
- 侧栏顶部两行：用户头像、姓名、编辑；记录对象头像、姓名、关系/年龄、切换。用户不标爸爸/妈妈；子女按性别显示女儿/儿子，其他对象保留已有关系。
- 界面身份姓名按 Unicode 字符脱敏：两字 `*末字`，三字 `姓*末字`；更长保留首尾并遮中间，单字完全遮蔽。姓名原件、账号编辑、正式档案和导出不改写。
- 侧栏主体为按今天/昨天/更早分组的现有对话历史。底部直接保留帮助、反馈、关于，删除可见「产品中心」标题。
- 主按钮沿用现有护护绿底白字。保存及整理结果的顶部入口继续依赖真实结果，不因视觉改版提前出现。

## 完整任务和状态

家长为当前孩子从症状记录页开始，语音或文字分段补充，按原流程核对并保存，再查看/整理/导出。底导、搜索、切换记录对象及侧栏历史不改变解析、保存、原件、归属或版本规则。

| 情形 | 约束及下一步 |
| --- | --- |
| 语音/文字切换 | 只有输入方式和分类可见性改变；已有文字/附件不删除、不自动发送。 |
| 进入用药/日常/回传表单 | 复用已有入口，先保留当前草稿和返回位置，按账号/对象标识返回。 |
| 切换底导 | 沿用已有离开保护；一键整理使用既有选择面板，不伪造整理完成。 |
| 历史读取/切换对象 | 只读当前账号和当前记录对象的历史；迟到结果丢弃。加载失败保留重试，空历史不伪造记录。 |
| 查看旧对话 | 打开现有历史详情/继续流程；原草稿和正式记录保留。新建对话沿用现有归档动作。 |
| 侧栏身份/编辑 | 两行摘要使用脱敏值；主动进入编辑后使用原始值，不修改存储姓名。 |
| 刷新/重新打开 | 恢复原草稿；文字输入恢复时分类同步可见，切回语音后收起。 |

## 输入区局部恢复：2026-10-29

用户要求恢复底部输入区：按住记录在左，键盘和拍照在右；文字模式才展开四个分类，分类只用文字，横向一排。恢复原有对话输入组件的排列与空输入行为，主记录按钮仍绿底白字。附件选择面板、录音按住/松开/取消、文字发送和草稿恢复沿用当前实现；不回滚上传识别、语音重试或其他已发布修复。

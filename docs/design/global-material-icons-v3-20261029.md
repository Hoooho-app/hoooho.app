# 全局功能图标替换 V3

产品主人于 2026-10-29 确认采用 V3 并授权全局替换。基线为 `main @ c28bfc054cce8013e842c8989551aaa163789b1a`，在独立分支实施，原工作区改动保留。

## 任务与边界

家长在登录、记录、日历、档案、整理导出与设置中，看到同一套容易识别的功能图标，并能区分真实选中状态。使用 Google Material Symbols Rounded，固定 wght 300、opsz 24、GRAD 0，图源固定到 `10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7`。

替换所有现有功能图标来源：Lucide、组件自绘 SVG、字符按钮、CSS 内嵌箭头、图标图片及隐藏模块。普通状态 FILL 0，真实选择/收藏状态 FILL 1。返回、关闭、保存、加载等动作不产生虚假持久选中态。CSS 选择器与组件的显式状态共用同一套原图。源路径不补绘，不按页面单独改变线宽。

保留当前布局、文案、点击区域、表单校验、录音生命周期、保存与错误反馈、路由权限和功能开关。最新主分支的文字分类入口保持文字。护士、头像、教程、品牌和精确人体定位图保留内容身份。Apple 登录与绑定统一品牌源，绑定处的水果图改正；微信与 QQ 使用品牌资产。没有准确同库图形的13种食物保留准确名称，网页与导出一致。

## 完整案例与状态

1. 家长在登录页选择密码、邮箱或验证码方式：未选项为空心，当前方式为实心，选择不会提前提交登录。Apple 保持品牌形状。
2. 登录后在症状记录、健康日历、孩子档案间切换：仅当前目的地为实心，返回或刷新依然依据路由，不依据上一次点击缓存。打开一键整理只表示弹层打开，不改造保存状态。
3. 从既有入口打开睡眠表单，填写入睡、醒来或进行中记录：月亮/太阳使用同库图形，保存、取消、编辑、删除及错误重试维持原业务。取消后不产生已保存反馈。
4. 保存后在日历、列表、详情与搜索查看：睡眠=bedtime、就诊=stethoscope、检查=lab_research、关注=favorite，跨组件同义复用。身体部位使用 person 与准确标签，人体图的位置与记录事实保持原状。
5. 查看忌口卡并导出图片：苹果、牛奶、鸡蛋使用同一套母版，其余食物直接读完整名称。图片加载失败不丢食物名称，不影响过敏或忌口归属。

选中状态从原业务的 checked、aria-selected、aria-current 或显式 selected 读取。加载、禁用、错误和保存成功不混同选中。图标默认装饰性，已有按钮名称、屏幕阅读器语义、焦点、键盘和原生选择器保留。

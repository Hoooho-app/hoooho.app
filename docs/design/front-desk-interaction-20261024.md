# Hoooho 首页交互与视觉修订

基线：origin/main `3c6d7c23872a20867fd68a8923d8162bba6d25ee`，工作树干净，独立分支 `feat/front-desk-polish-20261024`。本轮仅首页、其聊天/侧栏与必要历史入口，其他页面沿现有 Design System V2。此版替代已撤回的10月23日方案；未得到产品主人视觉验收前，不扩散到其他页面。

## 用户最终要求

- 页头保持护护 AI、搜索、更多。更多维持新建对话、分享护护、产品介绍。
- 首页侧栏去品牌Logo与显眼关闭叉，不留空位；完整菜单保留，点击空白、Escape、焦点回归均可关闭。
- 开场删“Hi，我是护护”，只保留“孩子的情况，慢慢说，我来记。”“记清楚，也方便交给需要的人。”原护士台视频144px，320px屏128px；主文案18px/16px。视频白底和文案处在同一白色接待面。
- 删除开场流程/近况框，换回原症状跟进模块；复用 useCases 和原有症状筛选/预览，保留查看跟进、一键整理。不同于上次，不调用完整健康事件列表并逐事件扇出读取原件。
- 纸底、松绿、暖色点缀；卡片可见但克制的浮起阴影。五个原标签保留名称、顺序与表单去向，恢复原分类浅色，触控至少44px。
- 聊天使用左右气泡、真实护士头像和原话；查看/重试/核对等按钮至少44px。
- 对话时间精确到分钟，来源是实际消息时间；首次、换日或间隔至少5分钟显示。健康事实的发生时间与聊天时间分开；缺失不编造。
- 默认按住说话，文字、相机、添加/发送放右侧；删去底部“AI帮你整理，保存前由你核对”整行。键盘和长文字输入继续使用同一输入位置。

## 阿福录屏中采用的交互规律

参考用户提供的72.7秒阿福录屏，采用其连续交互节奏。抽帧可确认流程，不据此声称精确动画时长或所有未展示手势的结果。

1. 按住：原页面仍在，底部浮现渐层、真实音量波形与计时；权限申请和实际录音分别表达，手指下的按钮不移动。上滑取消与失焦/页面隐藏沿原组件规则。
2. 松手：立即在同一线程显示一条语音原件气泡及聊天时间，之后用转写文字更新此消息。无转写时不是空白消息，失败保留原件。
3. 处理中：护士头像和等待气泡对应原识别任务的真实阶段。不制作假百分比或虚假的流式思考；原有暂停/继续/重试状态可用。
4. 整理完：实际回复与核对动作出现在对话里。记录助手负责整理事实，不引入医生诊断/治疗建议。沿用原解析、版本与确认保存约束。
5. 阅读：顶栏与输入栏固定，中部内容连续上移；用户上翻时停止强制滚底，提供44px回到最新消息入口。自己发出新消息后重新跟随；返回档案/核对时保留草稿与阅读位置。
6. 保存：出现真实回执，查看按钮可点且至少44px，原气泡继续保留，输入可继续。接收、整理与保存不可混为一谈。

本轮不增加医生智能体、自动播报、医疗建议、自动外发健康资料或归档内容重放。顶栏“分享护护”只分享产品链接；录屏的内容分享选择机制作为后续设计参考，不擅自引入。

## 实施边界与验收

共享组件只增加具名opt-in变体；首页之外现有调用不变。必要直接依赖为按账号+孩子鉴权的只读历史列表及原详情读取；不改数据结构、解析、保存和家庭独立项目。新建对话先保留本机原件，进行中的录音/识别禁止重置，不删已保存记录。归档只读。

验收覆盖320/375/390/430/620宽、短屏/键盘、长内容、无记录/真实跟进/读取失败、原件、录音取消与失败重试、编辑核对和保存、历史与新建隔离、减少动态。用实际运行页面截图校验，不以示意图代替交互验收。实体iPhone/Safari另列，不用浏览器模拟冒充真机结果。

交付链：本地验证 → 提交/推送 → main → Railway Production → 线上验证；不创建Staging，不等待重复部署授权。

# 食品标签核对

## 产品与数据边界

首页原功能网格末尾增加食品标签入口，沿用当前卡片、路由鉴权和设计系统。设计包的原始透明图标与英文拍摄示意图位于 `src/assets/food-label/`；示意图不参与识别。入口仅拍摄/相册；选图直接进入结果；补拍追加当前食品，重新拍摄清空。整页滚动、三列 68px 缩略图，没有保存、历史、手动输入、编辑或健康记录写入。

`POST /api/food-label/check` 使用现有服务端鉴权及当前成员归属/选择校验。照片、OCR 和结果仅在请求/页面内存；退出、刷新、pagehide、成员/账号切换或重新拍摄清除，旧响应通过 AbortController、任务标识和版本号隔离。响应 no-store；不使用业务缓存、数据库或临时文件。过敏档案只读，个人记录不发送给供应商。日志只允许模型、用量、耗时、状态等操作元数据，不记录标签内容或照片。

## 识别与规则

复用当前配置的百炼 qwen3.7-plus 服务端适配器：每张图一次结构化读取，合并后一次逐项翻译；无自动重试。最多6张、单张20MB、总量30MB、40MP；JPEG/PNG/WebP/AVIF/HEIC/HEIF，EXIF方向校正、2560px高质量压缩、不裁配料区。Sharp不能解码的HEIC通过heic-decode内存解码。

读取配料区、括号子成分、明确含有和交叉接触提示，要求摘录在本次OCR原文中出现。确定性解析保留顺序/子成分，不将百分比、维生素括注、ARA/DHA等名称注释伪造成子配料。翻译长度、顺序和原词必须逐项完全一致；失败保留已读原词，可靠原词的明确冲突仍可红色，其余待确认。

规则精确归一化同义词和已知衍生成分，不以任意子串判定红绿。明确匹配已确认记录为红；疑似/待排查及候选原料关系仅黄；来源不明、无摄入/耐受记录、无法可靠识别、未完整标签或缺少个人记录为待确认。否定声明不是阳性成分；可能含有/共线提示独立展示，不计为配料。不同具体坚果/鱼/甲壳类不自动互判。冲突数字按配料项计，不按过敏原种类。

## 验收与限制

食品模块单元、移动端 E2E、全量客户端、百炼与AI业务回归，以及TypeScript/生产构建需要执行。现有服务端 Operations 测试 `ops-service.test.mjs:62` 使用2026-09月固定失败快照，而history按当前时间清理30天前非保留快照；2026-10-04时它被清理，断言失败。相关源码与基线一致，本功能不修复这一独立问题。

真实验收使用公开英文Oreo包装配料照片，以及河北市场监管公开三元爱多恩中文包装PDF原始配料区域。测试使用独立虚构儿童与合成牛奶已明确/鸡蛋待排查档案；不是用户实际健康信息。`scripts/verify-food-label-release.mjs`显式启用后对真实部署接口识别、截图、核对档案未修改，并仅清理本次合成成员/档案。账号删除仍遵循现有身份验证流程，不绕过。

视觉/OCR完整性仍依赖模型对照片的可靠读取，规则无法证明像素中每个字绝对正确。不完整/模糊/翻译失败不允许绿色；红色可靠已读冲突保留。实际手机系统相机/相册和Safari HEIC端到端需要真机人工验收，桌面自动化仅验证capture、多选、方向与真实HEIC转换。

供应商配置为北京兼容接口。已核对阿里云数据留存文档：国际站ZDR范围不包含中国内地，不能据此确认当前北京业务空间的零留存；应用不会承诺第三方绝不保留数据。当前业务空间的具体留存/日志设置尚需供应商控制台核实，没有擅自修改供应商配置。

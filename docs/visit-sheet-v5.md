# 就诊情况单 v5：实现与验收记录

产品依据：用户提供的 v5 完整改造提示词、设计说明、会诊汇报交互稿、54 项设计审查。v5 覆盖本模块旧稿；未改其他产品模块、未引入演示项目、未把原型孩子或模拟临床数据放入运行时。

## 现状与改动边界

原有 `/visit-summary`、`/visit-summary/:eventId`、护士站入口与健康随记入口共用 VisitSheetReader。旧报告按章切换，附件只有索引，HTML 是只读输出。沿用已有账户、成员、记录、档案、观察、提醒、测量服务与 JSON 持久层。

本次修改：九章连续阅读、主诉后关联影像、真实来源的确定性整理、按主题保存选图、报告与源记录分开编辑、四种有明确范围的输出、独立可编辑离线 HTML、资源授权读取、回归与验收文档。没有新外部模型服务、图片识别、诊断算法、公共分享能力或数据库迁移。旧公开分享模块保持原有只读快照行为，不声称已升级成 v5 协作报告。

数据链：当前账号和成员 → `VisitSheetService.collect` → `report-model` + `v5-projection` → 持久化 schemaVersion 5 快照 → 阅读、来源、统计与导出。所有生产路径使用已有真实服务；`fixtures.mjs`、`tests/visit-sheet` 的虚构资料仅用于隔离测试。

### API 和兼容

- 原 `GET/PUT /api/members/:memberId/visit-sheet` 继续使用；PUT 增加 `selectedPhotoIds`，兼容原有 focus/question/notes/expectedVersion/requestId。
- 新增只读 `GET /api/members/:memberId/visit-sheet/resources/:resourceId`，供已存在健康档案中的 PNG/JPEG/WebP/PDF 原件使用。校验当前账户、成员和现存资源；no-store、nosniff；不读取任意远程 URL，报告 JSON 不含原件字节。
- 旧 schema 快照在重新读取后重建，保留可兼容的家长编辑。来源删除、权限或部分读取不能核验时不输出旧事实；更新失败不覆盖已存版本。
- `dataAsOf`、`generatedAt`、`editedAt` 分开；纯报告编辑不冒充病情数据刷新。
- `FactLineChart` 兼容增加 `scatter` 与显示域参数，其他使用方不改变默认行为。
- 本地 HTML 白名单 DTO 使用 SRC 编号替换数据库引用，不含账号令牌、内部资源地址或未选图片字节。每份文件有独立存储命名空间；修改不回写在线记录。
- PDF/其他非 raster 附件在线可读取原件，导出明确仅为索引；不声称文件已内嵌。单张大于 20 MB 或获取失败的图片明确列入未附清单。

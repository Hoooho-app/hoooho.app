# Hoooho UI 基准冻结 V1（已由 V2 取代）

> V1 的冻结状态已被全站视觉重构明确解除。当前基线与组件规范见 `docs/hoooho-design-system-v2.md` 和 `docs/ui-audit-v2.md`。

冻结日期：2026-08-09
基准提交：`c5f1b91`

## 冻结范围

- 登录与首次家人引导
- 健康事件列表与详情
- 健康档案
- 家庭成员与设置相关页面
- 侧边栏、弹窗及现有通用组件

## 冻结规则

1. 未收到明确页面修改任务时，不调整 UI 结构、布局、颜色、字体、间距、卡片和交互。
2. 数据、后端和 AI 功能通过 service、repository、adapter 接入，不把供应商逻辑写进页面。
3. 明确要求修改某一页面时，只修改该页面及其直接依赖，其他页面继续冻结。
4. 提交前检查 `git diff`，确认没有无关视觉变更。

当前 UI 是后续实现的设计基准版本。

# 忌口卡过敏食物清单

编辑页标题为“过敏食物清单”，仅展示明确不能吃的食物；添加和修改表单仅保留食物名称，新增项加入 avoid 清单。原有人工英文译名在名称未变化时保留，改名时清除旧译名；现有稳定食物映射继续提供英文，未知食物保留原名并显示缺少译名提示。

待确认 temporary 记录继续保存在原有快照和过敏资料中，不自动提升风险、不删除记录，但不进入本功能编辑页、出示正文、计数、译名检查及 PNG。只有待确认记录时展示空清单并禁用导出。保存明确清单时保留待确认条目和现有并发版本校验。

验证沿用 Client 领域测试和 dietary-card Playwright：待确认不出示或导出，保存保留原记录，新增 avoid，未知译名可导出原名，图标与 PNG 回退保持兼容。

# 就诊情况单 v6：概览优先与真实照片闭环

依据用户 v6 完整提示词、实际打开操作的交互 HTML 和总览图，在现有应用改造。v6 替代 v5 中冲突的展示规则；未改变两处入口、账号体系或其他模块的产品结构。原型中的孩子、数字、药物和模拟照片未进入运行时。

## 现状与边界

护士站、健康随记仍共同进入 `/visit-summary`；旧事件入口 `/visit-summary/:eventId` 仍使用同一 Reader。复用 `VisitSheetService.collect`、成员/事件/记录/档案/观察/提醒服务、JSON 持久层与现有附件存储。进入后生成已有资料的报告，再调整主诉、问题、照片。没有新演示项目、诊断模型、外部分析或自动发送。

只修改报告领域投影、Reader、离线输出、必要附件接口适配与测试；用药卡增加只读复用方式，原护士站可操作卡的行为保持不变。开发环境的附件读取和照片草稿路由与生产服务对齐；修复 Vite 已取消排队请求遗留账号锁的死锁，不改变生产认证契约。

## 真实组件与服务复用

- `MedicationReminderCard.tsx` 提取原 JSX 周历为 `MedicationCalendar`，原可操作卡与 `ReadOnlyMedicationReminderCard` 共用同一周格、状态和 `medicationCardLogic`。报告只提供依据按钮，不挂打卡、撤回、管理、滑动处理器。非当前周与所有未来节点（包括单周纯未来、当前周内未来）默认收起；打印展开全部周。
- `ReportDirectory` 使用现有侧栏样式、锁滚动和焦点钩子，不复用底部编辑面板。主诉/问题/照片仍使用已有 `BottomSheetSurface`。
- 整理者使用仓库现有虚拟护士图像 `nurse-station-idle-1-poster.webp`，明确“虚拟形象，未经医护审核”，不生成新真人头像。
- 相册图片复用 `prepareHealthImage`、`quickRecordService`、`QuickRecordPhotoService` 和 `EventAttachmentService`。上传完成只是草稿，报告 PUT 成功才保存。关闭、压缩取消、上传迟到和切换成员绑定各自会话并清理未消费草稿。

## 数据、API 与兼容

schemaVersion 升至 6，仍是同一报告身份与版本锁。旧报告读取后用现存来源重新投影；保留兼容的自选主诉、手写问题（包括空字符串）、历史说明、有效选图及版本历史。不是数据库破坏性迁移。

原 `PUT /api/members/:memberId/visit-sheet` 可选增加：

| 字段 | 含义和约束 |
|---|---|
| `photoDraft: {draftId, photoIds}` | 当前账号/成员的真实上传草稿；检查版本、授权和原件后消费；请求 ID 幂等 |
| `photoDetails[sourceId]` | 报告内家长标注的说明、部位、拍摄时间和精度；日期合法、不晚于当前时间；不改写原始附件 |
| `chapters[].overview` | 与详细事实同一服务端快照的概览，不在前端另编业务数字 |
| `medicationReminders` | 白名单的真实提醒计划、周节点及确认快照，所有引用可回到来源；无账号字段和可操作能力 |

保存过程在账号锁和现有 `accountTransaction` 内执行。照片写入“就诊资料照片”附件容器事件，不伪造症状记录、不调用 AI；二进制校验失败、冲突或事务失败保留旧报告与可重试草稿。拍摄时间未知保留未知，上传时间单独标识。只改说明不降低原有秒级时间精度。按规范化自填主题身份隔离选图，A→B→A 恢复 A 的有效选择。

主诉仍依最新有效症状的发生时间确定；附件/提醒不抢占主诉。病程只保留显式相关事实，1—4 个概览节点按发生时间排列，两个节点保留两端。箭头仅表示先后。时间按报告时区格式化，不能用 UTC 截日替代本地日期。

过敏状态缺失记未知；家长担忧不当确诊。观察统计只计有效、未撤回记录，结果未填不当无反应。提醒没有明确未用状态时不制造“明确未用”；未确认不当漏用。温度保留条件，身高体重分开，矛盾来源不择真。

## 输出范围与隐私

HTML 包含九章、全部文字来源、所选且成功读取的照片、问题与历史说明；可本地编辑并下载更新副本，不回写线上。重点 TXT 只含提炼事实、问题、来源编号及历史说明，不含全部原文/照片。AI 文本是摘要加全部来源原文，不声称有原图，不自动发送。打印展开详细正文、周历、图表、全部来源和所选照片，隐藏操作按钮。

导出前后校验来源与版本；来源变化或取消不生成旧文件。图片取消不仅隐藏 DOM，也从离线 JSON、脚本、资源和打印内容移除。离线白名单 DTO 用 SRC 编号替代内部引用，不导出账号令牌、账户 ID 或 API 地址。照片读取失败保留未附说明。搜索只影响阅读，不能缩减全量来源。历史补充不会随 UI 入口一起删掉。

# 孩子档案批量上传

孩子档案按钮直接调用原生 multiple file input；首次取消不离开首页，选完资料才打开上传资料区域。支持已接通的 JPEG、PNG、WebP 和 PDF（12份/12页、15 MB），图片/PDF 文件签名和服务端解码均校验，视频和音频不进入本入口。其他业务的媒体功能不变。独立继续拍照 input 仅图片、capture=environment；iPhone Safari 系统菜单与静态拍照行为待实机验证。

批次固定初始 account/member，新增只追加，点击开始整理才提交现有 `/api/members/:memberId/ai-drafts`。新增可选 `profileBatch:true` 和 `profileBatchId`（响应同名字段），仅用于本入口，不改变现有调用契约；失败恢复只接受同一批次草稿。该模式仍逐页 OCR 后一次上下文抽取，失败保留本地文件与服务端草稿，保存采用原事务、version 和重复保存幂等保障。未映射指标保留在附件 analysis.sourcePages，不据异常生成诊断；没有可分类事实时保存待确认原件记录。

结果为单个长表，按过敏、慢性、家族、手术、接种顺序显示非空组；其他资料和识别原文仍可核对。未知时间不以上传日期冒充发生日期。用户一次保存；识别失败不允许正式结构化保存。

可靠接种匹配要求同一成员、同一业务日、疫苗名称与明确剂次一致且唯一候选。仅补充缺失的 journal 字段及原件关联，不覆盖内容或已有字段。其他历史记录匹配需要事件日期及机构/反应等身份事实，名字相同不足以关联；不确定只保留资料，不弹重复警告。

首页不再进入旧智能记录中间页。旧路由及其资料查看能力暂保留兼容旧链接与既有附件，不删除历史数据或其他页面使用的识别组件。

# 成长数据参考值

身高与体重曲线在最新记录下方展示「标准参考值」，使用现有 WHO 儿童生长标准（2006）LMS 数据中对应性别、测量时精确月龄的 P50 中位数。小数月龄沿用曲线的 LMS 插值；身高为 cm，体重为 kg，均显示一位小数。

参考日期来自各指标最新的已保存记录，不受未保存的测量日期或输入草稿影响。暂无记录、缺少有效出生日期或性别、超出 0–60 月适用范围时显示「暂不可用」。目前仅支持此 WHO 标准；未来新增标准应同时更新曲线与参考值的数据来源。

同一页面先显示测量表单，再显示最新记录与曲线。记录列表通过顶栏右侧图标进入，保留原有历史、编辑、删除及返回草稿恢复流程。

验证：`npm run test:client`、`node --test server/growth/growth-measurement-service.test.mjs`、`npm run build`、`npm run test:e2e:growth-data`。在线页面验收须使用隔离虚构 API 数据，不修改真实健康记录。

## 实现及兼容

`front-desk-continuous.mjs` 在原有 context、facts、消息原件和 accountTransaction 上增加当前卡片投影。沿用现有 contexts 路由，增加 `current_card`、`edit_current`、`save_current`、`visit_checklist` action。保存回执记录真实成员、事件、记录和档案条目 ID；普通重试按稳定内容签名直接回放，跨页面真实修订仍拒绝覆盖。没有新数据库、迁移或付费依赖。

原话先保存到正式记录，结构化成功再更新同一 ID。原话、原件和历史原话版本保留。卡片手动修改有用户来源和版本；后台仅提取当前有效事实，卡片文本仍由用户编辑内容优先。编辑任务复用 RecognitionJobs，跳过已经完成的对话和转写；旧任务暂停并使版本失效。有限重试仅用于暂时失败的后台整理，不重试保存操作。只建立普通事件，显式 `caseTracking:false`；不删除既有跟进数据。

旧草稿保持兼容；旧单条保存回执可按精确 ID 接续，多条旧记录保持原有独立链接，不擅自合并。日历和档案的独立智能记录流程保留；前台不再进入独立核对页。修改仅针对前台和直接依赖，连接恢复、登录、护士素材、提供商配置及其他页面结构不变。

原 V3 首页/回滚测试中关于五入口、阻断动画、独立核对、对象确认和跟进开关的旧断言由本次明确产品要求取代；新移动端套件覆盖当前契约，旧导航、历史、媒体恢复、独立智能记录及数据兼容测试仍保留。历史冻结哈希仍记录在 baseline.json 的 supersededInteractionFiles，未改动的数据边界继续按原哈希校验。

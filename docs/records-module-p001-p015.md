# 健康随记记录模块实施与验收清单

本清单对应 2026-09-22 已确认的 P-001 至 P-015。它用于约束实现与验收，不扩展全局导航、成员规则、就医准备或其他冻结模块。

- [x] P-001 记录入口仅保留记录症状、记录日常、记录就医、记录用药四项，四项均可真实保存且草稿隔离。
- [x] P-002 复用健康随记公共头部、当前成员、设计令牌及移动端容器，不引入原型外壳或示例身份。
- [x] P-003 症状从文字/语音描述开始，安全提取摘要和部位，支持失败、空结果、手动修正及异步版本保护。
- [x] P-004 复用完整症状多选和身体部位定位器，保留多点、体表/内脏、四肢细分及返回状态。
- [x] P-005 症状补充信息默认折叠，仅含主观严重程度、可能诱因和日常/就医/用药三类补充。
- [x] P-006 症状补充优先展示发生时间附近的真实已有记录，支持逐条/全部带入、查看、线索移除和正式补录。
- [x] P-007 主入口与嵌套补录复用同一正式表单、校验和保存逻辑；返回上下文、稳定关联和幂等性正确。
- [x] P-008 日常仅含饮食、母乳亲喂、配方奶、瓶喂母乳、辅食、营养补剂、睡眠、排便；补剂归日常。
- [x] P-009 日常表单仅保留核心结构化事实、实际发生时间和补充症状；睡眠保存真实起止区间并支持跨日。
- [x] P-010 就医由医院资料驱动，支持拍照/相册/文件、整理、原件查看、核对修改和原件保存。
- [x] P-011 就医识别使用现有真实服务，保存来源与修改状态，正确处理不确定、冲突、删除、过期响应和失败降级。
- [x] P-012 用药仅保留药品、实际用量、单位、实际时间、对应症状和补充就医；保留多药能力。
- [x] P-013 编辑、补录、保存和再次编辑均严格执行最终允许的关系矩阵。
- [x] P-014 记录、草稿、附件和关联按账号/成员隔离，游客与历史数据兼容，实际发生时间和稳定 ID 不丢失。
- [x] P-015 覆盖加载/空/失败/重试/上传/识别/保存/返回/刷新/成员切换/重复点击，并验证 375x667 与 1440x900。

## 必验完整路径

- [x] 症状描述 → 提取 → 手动修改 → 保存 → 再次编辑。
- [ ] 症状带入已有日常 → 补录饮食 → 返回并关联 → 保存症状。
- [ ] 症状补录跨午夜睡眠并展示真实区间。
- [x] 营养补剂保存后仅出现在日常及症状日常候选，不出现在用药入口。
- [x] 饮食、喂养、睡眠、排便只提供补充症状关系。
- [ ] 多份就医资料整理、原件查看、修正、保存和再次打开。
- [ ] 就医识别失败/部分失败仍保留原件，可重试或只保存原件。
- [ ] 整理期间删除/替换原件后旧结果不回流。
- [x] 用药选择药品、用量、单位并关联症状和就医后保存。
- [ ] 取消补录、保存失败、重复点击、切换成员、刷新和游客合并不丢失、不串人、不重复。

> 未勾选路径已经有对应领域/服务层覆盖或实现保护，但本轮没有把整条路径全部跑成浏览器端端到端用例；不得仅凭局部自动化结果将其标为已验收。真实语音设备和带生产凭据的资料识别也仍需在受控环境人工验收。

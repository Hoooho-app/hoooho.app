# 症状记录入口

`/smart-record` 直接复用健康随记的 `SymptomRecordFlow`，标题为“症状记录”，底部保存；原健康随记入口仍叫“记录症状”。表单、部位定位、照片、严重程度、发生时间和点击式语音共用原组件。

保存继续使用 `POST /api/members/:memberId/case-records`，兼容旧请求，新增可选 `journal`、`photoDraftId`、`photoIds`。后端使用既有 journal 校验与照片草稿服务，在同一账户事务内保存症状、关联照片、消费草稿。事件与观察任务参数保留；任务记录仍要求明确选择观察结果，不默认补为正常。

此入口的文本草稿按账号、人物、事件、任务隔离；保存失败保留表单，保存请求 ID 在刷新后复用，成功后清理。已有智能收记 IndexedDB 草稿保留原样，不自动将旧原件或待核对资料转换成症状事实。其他智能整理入口及 AI/Parser 规则不变。

验收：`tests/case-continuity/symptom-record.spec.ts` 和 `server/events/case-continuity-service.test.mjs`；覆盖 375/390/430、空表单、结构化保存、照片、草稿恢复、失败重试、事件关联、观察反馈与点击语音。

症状表单的主诉标题为“症状描述（主诉）”；同一主诉卡片内，输入框下方放置“拍摄”“照片”和加宽的点击式“语音输入”。拍摄使用 video/* + capture="environment" 请求后置摄像头录视频；照片使用 image/*,video/* 系统图库选择器，允许照片和视频混选。浏览器对原生拍摄入口的实现由设备决定，真实手机仍须验收。所有复用症状入口同步，其他记录表单继续使用原图片入口。

## 媒体上传、核对及保存

症状资料走 `POST /api/quick-records/:draftId/media` 的二进制流，不把大视频编码进 JSON。视频上限 100MB、120 秒；图片上限 25MB、解码 4000 万像素；每次表单最多 6 份。服务端校验实际容器/时长，MP4、MOV、WebM 解码后提供 H.264/AAC MP4 与 JPG 封面，原件保持字节不变。HEVC 通过 FFmpeg 解码；HEIC/HEIF 取决于运行环境实际解码能力，无法读取时明确提示从系统相册导出 JPG，不宣称所有 iPhone 原件已兼容。超限要求裁剪/导出后重选。

Linux Railway 运行层通过 `railpack.json` 安装 FFmpeg；Windows 开发测试二进制为开发依赖，不用于 Linux 发布运行层。

上传成功后自动启动后台任务，`GET /media/:id/review` 轮询；`POST` 显式指定 audio/vision 仅重试该阶段；`PATCH` 保存用户核对的编辑文字。上传、音轨转写、采样画面和核对为独立阶段，没有收费自动重试。相同上传 ID 在同一账号/人物/草稿内幂等。任务重启中断会明确失败并提供主动重试，删除/取消后的旧任务不能回写。

复用已配置的百炼 ASR 与视觉适配器。视频音轨转为单声道 16k WAV 独立转写；视频画面最多 6 个时间点覆盖起止，逐帧编号和采样秒数保留。视频转写、画面整理可部分成功。无法声称采样之间的动作；咳嗽等非语言声音尚未识别，无转写不表示没有相关声音。图片保留可见外观或可读医疗文字的附件来源。没有足够信息时保留原件，不生成正常或确诊结论。

草稿分别标记家长描述与画面可见，全部待核对。用户修改优先，确认应用只追加，不覆盖正文或自动改变部位；应用 ID 持久化防重复。正文/补充合并最多 1000 字，超限请精简后再应用，不静默截断正文。历史图库缺少可靠参考日期时保持未知，新拍原件保留用户时区及参考日期；相对时间需用户核对，保存时间精度可为 unknown，不以上传日期替代病情发生时间。

上传失败明确显示文件级错误及重试/移除，已有文字和成功原件可先保存。只有原件时通过用户确认保存为“症状待补充”，记录为 other、发生时间 unknown。上传与整理中保存保留原件，未完成阶段标记未完成。保存后的记录详情可读取授权原件、兼容视频及核对来源。

文字/服务端草稿按账号、人物、事件与任务隔离。本地待上传 File 使用 IndexedDB 保留最长一天，成功、移除及取消后清理。浏览器存储不可用会提示重选；Blob 和播放器关闭会释放，Portal 预览自身样式不依赖护士页面 CSS，不挤开表单。

日志仅记录任务/请求 ID、阶段、耗时、状态、错误码和调用统计，无原件、医疗正文或密钥。review.calls 表示本次阶段服务尝试/结果，真实供应商请求需结合既有百炼/ASR 安全诊断确认；不推测历史累计调用。

测试：`server/ai/symptom-media-*.test.mjs`、`server/events/symptom-media-upload.test.mjs` 与共用症状浏览器测试覆盖格式、时长边界、独立失败、主动重试、迟到取消、来源、核对、保存、恢复和移动宽度。测试替身不算模型验收。真实 iPhone Safari 系统录像/相册、播放和切后台全过程必须另行实体设备验收，Chrome 设备模拟不能代替。

# 就诊情况单阅读与整理（2026-10-08 确认实施）

只调整就诊情况单，沿用 Hoooho V2。顶部保留目录、导出；目前情况默认展开，问题、相关经过、资料档案默认收起，编辑放在展开内容内。

## 数据与交互

打开时检查当前孩子的已保存资料；指纹变化自动整理。保留主诉选择、家长补充、人工问题、影像选择和明确设置的范围。无变化不产生新版本；实际来源读取失败保留已有快照并提供重试，不用缺失来源覆盖旧稿。纯报告文字修改不推进资料截至和生成时间。

摘要的每项引用现有来源。匹配症状须约束部位，不把同属皮肤类别的颈部与臀部症状混合。日常背景默认取最新相关观察前七天至后两天（不超过当前时刻）；明确关联可超出该窗口。时间接近只代表上下文，不能确认医学关联。

相关经过以分类摘要展示已有症状、饮食、睡眠、排便、体温、用药/补充剂、明确关联的就诊和处理。空类别不显示，全部为空则隐藏整张卡。连续数值有多点时显示图，单点保留数值；事件原话、时间线和来源按需查看。睡眠时长只描述记录的单段，不能代替每日总量；记录空白不能补为正常。已确认过敏项与记录食物精确重合时提示核对，不自行诊断过敏。

用药实际记录、已执行提醒、计划剂量/频率/疗程分开，计划和未确认节点不能冒充已服或未服。补充剂可供本次咨询核对，不能据此声称因果。问题生成十个候选，默认展示前三个；编辑页剩余七项整行可追加，追加后可修改，不重复追加同一项。人工问题包括明确清空均保留。

资料档案按过敏史、慢性病史、家族史、手术史、疫苗顺序，只展示有记录类别。过敏只显示已明确/疑似标签；已排除和可耐受不作为过敏项。成长概况复用现有 WHO 年龄/性别参考，待核对测量不参与；不同测量方法不直接合并比较，不由百分位单独判断发育。

上传影像保存到对应健康随记记录，复用附件身份；没有症状记录时创建影像专用随记，不编造症状或拍摄时间。保存事务失败回滚，幂等重放不复制图片；取消展示不删除原件。已有记录选图只引用原件。导出与阅读复用摘要，完整原文保留在来源附录，离线影像必须内嵌成功读取的原件字节。

署名使用已保存的主要记录者称谓，不带全名；称谓未知则写“由 Hoooho 护士配合家长整理”。

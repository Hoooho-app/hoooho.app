# 一键整理

首页与侧边栏的统一入口打开三项选择：就诊情况单、照顾交接单、近期情况回顾。旧情况单链接、头部、目录、全部内容与三个导出动作直接复用，不增加更新按钮。

照顾交接单呈现每天固定安排、需要留意、家长交代。只将家长明确设置的日常规则/用药计划作为固定安排，不从单次随记推测作息。允许编辑本次分享快照，不回写健康记录。分享先校验来源指纹，再保存独立草稿；相同分享令牌不得替换内容；公开快照不携带未选择的原始章节。旧分享仍能打开。

近期回顾并行读取当前成员的journal-index、cases、过敏档案与用药安排。症状图展示症状相关事件分组（索引分类，不声称真实发作次数），合并跟进和event-update去重，以首次明确记录时间归期；未观察到/未确认外部AI记录不计入。反应仅按实际反应记录，档案状态不代表每次反应已证明因果。无时间不落入今天；无睡眠/奶量数据保留空值，不当作零。

睡眠图仅用起止完整、已结束的夜间记录，时长是单次记录均值，入睡为分段中位数，跨午夜连续排列。奶量只汇总明确瓶喂毫升数。用药比例是已到期安排的完成记录占比，不称按时率。补剂/外用仅统计实际记录，不推算不存在的历史执行分母。日期按北京时间，半年/一年是日历范围；短范围按天或5日分段，长范围按自然月（首尾可能非完整月）。记录明细可以查看原始记录。

## Design System 扩展

FactDistribution 增加可选unit和showPercent，默认原样。FactBucketChart为通用日历分段折线/柱形图，支持空值断线、单点、键盘访问与分段明细；同时用于症状、睡眠、奶量图。颜色和页面排版沿用hoho tokens，无依赖新增。情况单自身组件未改动。

## 验证

新增统计口径、成员隔离、去重、日期边界、睡眠空缺、用药撤销与过敏反应来源测试；交接草稿快照、大小限制、重试幂等与不可替换测试。浏览器覆盖入口、分享、编辑、日期范围、导出和原情况单回归。移动宽度为浏览器模拟；未声明实机iPhone Safari验证。

入睡规律同时呈现入睡时刻中间50%的跨度（分钟，至少2条有效记录），数值越小表示记录中的入睡时刻越集中；不自动判断健康与否。图表导出为离线HTML快照，包含所选范围和统计口径。

## 2026-10-17 页面精修

三页采用统一返回箭头。整理入口携带原页面路径、query/hash、路由state与history index：可后退到直接来源时使用router返回；重载/历史不匹配时replace到保存的来源；直接进入无来源时回护士站。保留情况单编辑器的离开保护。

新增Design System通用ProcessingState，使用真实请求阶段及已完成资料请求数（回顾4项并行），其余请求用不确定进度条，无计时模拟百分比和人为等待。已存在报告的读取失败仍保留旧报告供恢复。

情况单默认收起目前情况，目录可主动展开；头部间距、图标和触控高度一致。章节顺序为目前情况→相关经过与处理→完整资料档案→本次想问，问题按问题一/二等排列。仅隐藏重复的symptom经过分组，原记录和导出原始依据不删减；三种导出不变。HTML问题章节同步置底。

MemberIdentity在情况单/交接单复用交接资料卡结构，身高/体重/ABO小字左对齐；保留测量来源。当前成员沿用其头像，缺省用年龄匹配的内置虚拟头像。公开交接只从分享快照生成头像，不读取接收方当前成员，也不引入私人头像URL。

固定安排为时间＋事项的紧凑行，按明确时刻升序；同日多次安排拆为对应时刻，跨午夜标次日，间隔用药保留原规则。仅识别独立时刻字段；说明中的时间不拆出，不改写否定/限制指令。编辑与分享保持原始行，公开页面复用同一展示投影。去除来源/北京时间等重复标签。长医嘱保持完整可读，不截断用量或限制说明。
